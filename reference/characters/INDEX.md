# キャラデザ参考

**目的：** 4機体（METEO / VIPER / BASTION / CANNON）のシルエット・配色・ディテールの方向性を固めるための参考集。

**仕様書参照：** §11（プレイアブルキャラ）/ §2 開発者プロフィール（3Dアニメ内製前提）

## 共通方針メモ

- **メカは重い**（北極星3）— 重量感のあるシルエット、過剰に細身にしない
- **キャラには金をかける**（アセット調達戦略）— 細部ディテール優先
- 配色は機体ごとに**1色テーマ**で識別性を持たせる（混戦時に瞬時に区別できること）
- **基本約6頭身**（2026-05-15 確定）— 重メカだが人型ヒロイックの可動範囲を保つ等身。**ゲームに入れた時のバランスを見て微調整**
- **体長 20m**（2026-05-18 確定）— ゲーム全体のスケール基準。背景・敵・プロップすべてこれに合わせる
  - 含意：背景物の階高・配管径・タンク径は普通の参考画像から **2〜3倍誇張**が必要
  - ベルスク帯幅（Z ±380wu）との比率も実装時に確認
- **共通コンセプト：ヒロイック + 各機体固有モチーフ**（METEO は炎）
