# METEO

**目的：** バランス型・前方ガード機の参考集。

**仕様書参照：** §8 キャラクター設計 / §9.0 攻撃 ID 命名規約 / §9.7 必殺技 / `chars/char01.md`

## デザインコンセプト（2026-05-15 確定）

### コア概念
- **ヒロイック + 炎** — 主人公機としての王道のかっこよさ × 炎モチーフ
- **頭部からずっと炎が出ている** — 常時着火状態。アイドル時も含めて消えない
  - これにより一目で「METEO」と分かるシルエット成立性が出る
  - 板野演出（噴射軌跡）とも親和性が高い
  - **属性「火（燃焼DoT）」**（仕様書 §8）と完全整合
- **約6頭身** — 重量感のあるメカだが、人型ヒロイックの可動範囲を保つ等身
  - 全キャラ共通の基本比率（VIPER/BASTION/CANNON も同じ等身想定）
  - **ゲームに入れた時のバランス見て修正可**（仮置きの数字）
- **体長 20m**（2026-05-18 確定）— 全キャラ共通のスケール基準
  - 背景物のスケール感もこれに合わせる（巨大化前提）

### ゲーム上の役割（既定）
- バランス型（攻防両立・色=赤・属性=火・メーカー=EVOL）
- L キー = 前方ガード（押しっぱなしで SP 持続消費・移動可・攻撃不可）
- 火属性副次効果：ヒット後の燃焼 DoT 継続
- パイロット要素も含むか機体のみかは未定

### 武器ビジュアル候補（2026-05-15 追加・2026-05-17 整理）

**位置づけ：** 仕様書側の技構造（`c01_atk_NN` / `c01_add_NN` / `c01_sp_NN`）は既に確定済み。
これらの武器は**既存の技枠に「見た目」として載せる**ビジュアル提案であって、新規技を追加する話ではない。

#### 候補3種

| 武器 | ビジュアル性質 | ヒロイック + 炎 整合性 |
|------|--------------|-------------------|
| **パイルバンカー** | 単発高威力の近接刺突。チャージ展開→打突→排煙のドラマ性 | ヒロイック性◎（一撃必殺の見せ場）／炎との繋がりは間接的だが、打突時に火花/排煙で炎演出と接続可 |
| **火炎放射器** | 持続範囲攻撃。前方扇形の継続炎・燃焼DoT との視覚的因果関係が明白 | **炎モチーフ直接的**／**仕様書 §8 の火属性「ヒット後の燃焼DoT継続」**と視覚一致 |
| **ドリル** | 連続ヒット型の近接刺突。突進＋多段ヒット | **Powered Gear の直系オマージュ**（最大の影響元）／**仕様書「中間ノックバック設計」（突進系の連続ヒット）**と既に技術仕様も整っている |

#### 既存技枠への割り当て候補（あくまで方向性）

仕様書 §9.0.3 の METEO 確定表に対して、武器ビジュアルを載せる候補：

| 既存技 ID | 入力 | 中身 | 載せる武器ビジュアル候補 |
|---|---|---|---|
| `c01_atk_01〜04` | J 連打 | 弱チェーン | 素手 / 軽い打撃（ベース）。最終段 04 にドリル始動の予兆を入れる手も |
| `c01_add_01` | →J | タックル | **ドリル前方突進**（多段ヒット・ライドアロング設計と相性◎） |
| `c01_add_02` | ↑J | 軽い浮かせ | 上方向のドリル突き上げ／パイル軽打 |

| `c01_sp_01` / `_air` | K | 波動・弱ビーム | **火炎放射器**の前方扇形（地上）／斜め下噴射（空中） |
| `c01_sp_02` / `_air` | ↑K | 粉塵昇竜 | 上方向の火柱噴射 |

### 既存仕様との整合性

- 仕様書 §8：METEO 属性=火（**燃焼DoT**）→ **火炎放射器**が視覚因果として最も自然
- 仕様書「中間ノックバック設計」：突進系の連続ヒット技にライドアロング → **ドリル**実装の地ならし完了済
- 仕様書 §9.7 必殺技強化チップ（PLASMA INDUCER / ANTI-AIR ROCKET / BURST CORE）：装備時のみ強化版発動 → **武器ビジュアルもチップ依存で切替可**な拡張余地あり

### 参考作品との接続

- **パワードギア**（最大の影響元）：「ドリルで敵を貫いたりがかなり気持ち良い」というユーザー言及あり（research/capcom-belt-reception.md 参照）
- **火炎放射器系のメカ題材**：要追加リサーチ（コア系・サクラ大戦・スーパーロボット大戦の特定機体等）
- **パイルバンカー系のメカ題材**：要追加リサーチ（ボトムズ・ガンダム ASW-G 系・アーマードコア等）

### デザインの整合性
- 既存設定との繋がり：
  - METEO 属性「火（燃焼DoT）」（§8）— **炎コンセプトと完全一致**
  - 名前 METEO = 隕石＝燃える落下物のイメージ
  - 北極星「板野思想（推力理由）」— 頭部炎は常時推力の象徴として機能
