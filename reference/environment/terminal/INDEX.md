# ターミナル（拠点）

**位置づけ：** 4機の出撃拠点。チップ装備・メカ修理・出撃地点。**ゲーム内で唯一仕様書に明文化されたロケーション**。

**仕様書参照：** §5（世界観）／ §13.0（ターミナル形式・段階実装）

## 仕様書からのヒント

- **宇宙公園跡地**（仮置き・ストーリー確定で変動）
- 奥に**朽ちたパラボラアンテナ群**
- 手前に**各キャラがスクラップで作った拠点**が並ぶ
- メカが歩いても違和感ないスケール感（搭乗解除しない・パイロット人型は作らない方針）
- AI 仲間（傭兵モード）はターミナル内では動かさない

## トーン

- 2099 年・近未来 SF
- 王道少年メカもの寄り（暗くなりすぎない）
- 「廃墟だが希望が残っている」雰囲気
- 段階C（最初）は背景イラスト or 簡素 3D 静止画 + 従来メニュー UI で済ます
