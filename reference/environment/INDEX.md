# 背景・ステージアート参考

**目的：** SCRAP BLITZ の各ロケーションの方向性を固めるための参考集。

**仕様書参照：** §5 世界観 / §7 ステージ構成 / §13.0 ターミナル / §26 アセット調達戦略

## 構造ルール

```
environment/
├── terminal/                ← 拠点
├── act{N}_{theme}/          ← Act = テーマ単位
│   ├── INDEX.md             （Act 全体のトーン・ボス情報）
│   ├── stage1/              （Act 内のサブシーン 1）
│   ├── stage2/              （Act 内のサブシーン 2）
│   └── stage3/              （Act 内のサブシーン 3・ボス戦想定）
└── synty-candidates/        ← Synty 購入候補（横断用）
```

- **Act = テーマ単位**：1 ボスに対応する大区分。テーマ名は英語短縮（factory / urban / orbital 等）
- **stage = Act 内のサブシーン**：道中の場景遷移を 1 Act あたり 3 シーン程度で区切る
- **数は柔軟**：本作はベース 3 Act 想定だが、増減自由（Act 4 以降を将来追加する場合は `act4_{theme}/`）
- テーマ確定したら `act{N}_TBD/` → `act{N}_{theme}/` にフォルダ名変更

## 共通方針メモ

- ベルスクの「帯」幅（Z方向 -380〜+380）に収まるレイアウトを意識
- 16:9 固定・1920×1080 で破綻しない密度
- **背景・UIは購入アセットOK**（キャラに金を集中させる方針）
- **Synty POLYGON Sci-Fi 系購入 + 3DSMax で部分手直し**が基本ライン
- 2099 年・近未来 SF・王道少年メカもの寄り（暗くなりすぎない）
- 「リスペクトでありパクリではない」「楽しさの言語化を主軸」のスタンスは total-art と同じ

### スケール基準（2026-05-18 確定）

- **主人公機体長 20m**（全キャラ共通・characters/INDEX.md 参照）
- 背景物（建物・配管・タンク等）は普通の現実参考から **2〜3倍誇張**して描画
- 一般的な工場/廃墟写真を直接使うと「ミニチュアセット感」が出るリスクがあるため、要スケール調整

### 世界観美学（2026-05-18 確定）

- **「希望寄りの廃墟」**を貫く
- 晴天・明るい色味・植物の侵食（自然が取り戻している感）
- 完全廃墟・暗くじっとり系は採用しない
- 北極星「暗くなりすぎない」（§5）と直接整合
- ガオガイガー的「AI に取られたがまだ取り戻せる」雰囲気
