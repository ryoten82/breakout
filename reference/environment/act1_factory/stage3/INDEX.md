# Act 1 / Stage 3 — 中央プラント／SF色のヤバい何か（ボス戦エリア）

**位置づけ：** Act 1 ボス戦シーン。**ボスはランダム化される予定**のため、stage3 の絵はボス固有要素を作り込まない。

**親 Act：** [../INDEX.md](../INDEX.md)（Act 1：factory）

**重要方針（memory `project_scrapblitz_boss_randomization.md`）：**
- Act ボスはランダム化される可能性が高い
- **ステージ装飾にボス固有要素を埋め込まない**
- → stage3 の絵は「**汎用のヤバいボス戦エリア**」として作る。どのボスが来てもハマる空間に

## このシーンのコンセプト（ユーザー発言・2026-05-19）

> なんか**奥の方で色々ヤバそうなのが作られてる…？という感じ**を出したい。
> ステージ２までの**普通の工場感から SF 色を足す**。
>
> （補足 2026-05-19）ボス自体はランダムにしたいという考えもあるので、**あまり背景とボスの見た目は同期させない予定**。

### 確定したデザイン方針

| 要素 | 内容 |
|------|------|
| **トーン転換** | stage1/2 の「現実的な廃工場」→ stage3 で「SF 色」が混入 |
| **奥行きの使い方** | 手前は通常工場・**奥で何か異質なものが組み上がっている**気配 |
| **「ヤバそう」の出し方** | 不明瞭な巨大装置・青や赤の異質な光・チューブ・配線の海・人ならざるサイズ感 |
| **物語接続** | OVERLORD（AI ネットワーク）の侵略・工場が乗っ取られて**何かを生産している**暗示（特定ボスではなく汎用） |
| **ボスとの非同期** | **背景に特定ボスを匂わせる要素は入れない**。どんなボスが来てもハマる「汎用のヤバい空間」として作る |

### 設計のコア

「**異物侵入**」の構図：
- 工場というプレイヤーが認識しているコンテキストの中に
- **不釣り合いに巨大／不釣り合いに高度／不釣り合いに発光する何か**が紛れている
- それが**「何のために作られているか分からない」**ことが不安感の源

→ この「分からない」を保つことが、ボス汎用性とも整合する（特定の何かを示さない方が、どんなボスでも違和感なく登場できる）

## ステージ２→ステージ３のトーン遷移設計

このシーン構成は**3段階の SF 度上昇**で組める：

| 段階 | 絵 | 該当参考 |
|------|----|---------|
| **A. 普通の廃工場（接続）** | 通路・グレーチング・配管。stage2 と同質 | `002218.png` |
| **B. 異質な空間に踏み込む（転換）** | SF 通路・異質な照明・形状の幾何化 | `002535.png` |
| **C. 何かが作られている／生産ライン** | 整然と並んだ武器・量産設備 | `002426.png` |
| **D. ヤバさのピーク** | 巨大で意味不明な装置・チューブ・発光 | `002925.png` |
| **E. ボス登場** | 赤い演出空間・**汎用台座**からボスが起動（ボス形状は問わない） | `002805.png` |

→ stage3 内を **A → B → C → D → E** の5段階で遷移させる構成案。
→ ボス戦広場は **D の前室（広い） + E の台座中央**で構成。
→ **E の台座は汎用形状**にして、ランダム抽選されたボスがどれでも乗れる作りにする。

## 設計上の論点（実装時に詰める）

- **「ヤバさ」の段階表現**
  - 入り口は普通／奥に行くほど青く光る／最深部で完全に異質、というグラデーション
- **量産ラインの中身（ボス非依存）**
  - `002426.png` のような「何かが量産されている棚」を背景に置く案
  - 並べる対象は**雑魚メカパーツ／武装／不明な部品**等、ボス固有形状ではないもの
  - プレイヤーが「ここで何かを作っている」と感じる程度に留める
- **色のトーン**
  - 工場ベース＝鉄＋黄黒警告色 → SF部分＝青系発光が混ざる → ボス戦広場で赤に転換
- **ボス登場演出（汎用化）**
  - `002805.png` のような台座起動演出
  - **台座は汎用形状**（円形シャフトリフト・四角昇降台等）でどのボスも乗せられる作り
  - 「乗っ取られた工場が**何か**を組み上げていた」というストーリー解釈は維持・特定ボス名は出さない
- **OVERLORD への伏線（汎用化）**
  - 「これは Act 3 で対峙する OVERLORD の生産機構の一部」という暗示を埋め込める
  - 抽象的な異物・量産ライン・巨大装置という形で、特定 Act 1 ボスを示さずに伏線化可能

## 仕様書／世界観との接続メモ

- **§5 世界観**：「AI ネットワーク OVERLORD が世界を侵略開始／各国の戦闘メカが乗っ取られ無人で人類を排除」と整合
  - stage3 で「乗っ取られた工場が敵メカを量産している」描写が世界観の説得力を上げる
- **「希望寄りの廃墟」美学**：stage1/2 で確立した方針との緊張感
  - stage3 だけは「**希望が薄れる**」絵に振ってもいい（ボス前で危機感を演出）
  - ただし暗すぎ・じっとり系には振らない（北極星「暗くなりすぎない」）
- **ボスのランダム化方針**：memory `project_scrapblitz_boss_randomization.md` 参照
  - Act ボスは複数候補から抽選される予定
  - stage3 の絵に**ボス固有要素を埋め込まない**（特定ボスのシルエット・色・モチーフを背景に出さない）
  - 「何かが起動した」「何かが組み上がった」という**抽象的な不安感**で受け皿として汎用化

## 残課題・相談メモ

- A〜E の5段階遷移、全部 stage3 内でやる？それとも前半は stage2 後半に吸収？
- 量産ラインに並んでいるのは**雑魚敵パーツ**か**汎用武装**か（**ボス固有形状は避ける**前提）
