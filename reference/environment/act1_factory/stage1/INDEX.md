# Act 1 / Stage 1 — 外周ヤード（工場外周・侵入導線）

**位置づけ：** Act 1 開幕。プレイヤーが工場群に侵入していく開けたヤード。**ステージ最後に大きい工場の車両用入り口**があり、そこから次のシーン（stage2）へ侵入していく動線。

**親 Act：** [../INDEX.md](../INDEX.md)（Act 1：factory・CRUSHER 戦）

## このシーンのコンセプト（ユーザー発言・2026-05-18）

> 基本的に**晴天**。
> **奥の方に乱立している工場が見えている**。**パイプやタンク多め**。
> 主人公たちが結構大きい想定なので（それぞれ**体長 20m くらい**）背景のスケール感もそれに合わせる。
> 地上はある程度**舗装されているが、廃工場なので所々剥げており、緑が突き破ってきているところもある**。
> ステージ最後に**大きい工場の車両用入り口が開いており、そこから侵入していくイメージ**。
>
> イメージ的に一番参考にしているのが**ゲーム アークレイダース（ARC Raiders）の空港内にある廃工場**。

### 確定したデザイン要素

| 要素 | 内容 |
|------|------|
| **天候・時間帯** | 晴天（明るく開けた絵） |
| **背景の深度** | 奥に工場群が乱立（重層的なシルエットで深度を作る） |
| **要素密度** | パイプ・タンク類が多め（工業地帯の情報量） |
| **キャラスケール** | 主人公機体長 **20m** — 背景もそれに合わせて巨大化 |
| **地面** | 舗装ベース・剥げ・植物が突き破る箇所あり |
| **終端演出** | 巨大な車両用入り口が開いている → stage2 への侵入導線 |
| **最重要参考** | **ARC Raiders 空港内の廃工場** |

### スケール感の含意（重要）

20m キャラが歩く前提なので、**背景の建物・配管・タンク類はすべて巨大スケール**に作る必要がある：
- 普通の工場リファレンスを使うと「ミニチュアセット感」が出るリスク
- 建物の階高、入り口高、配管径、タンク径すべて見た目を**2〜3倍に誇張**する
- ベルスクの「帯」幅（Z ±380wu）に対しても、奥行きの工場群は十分なスケール感が出る配置

### 「廃」だが「希望」を残すトーン

- 完全廃墟ではなく**晴天 + 植物の侵食**で「自然が取り戻している」明るさ
- ガオガイガー的な「人類の生産拠点が AI に取られたが、まだ取り戻せる」雰囲気
- 暗くじっとりした廃工場ではない（北極星「暗くなりすぎない」と整合）

## 設計上の論点（実装時に詰める）

- **「奥の工場群」の見せ方**
  - bgCamera（Perspective・FOV5）でどこまで深度が出せるか
  - シルエット重視（細部は省略）か、ディテール込みか
- **植生の入れ方**
  - 舗装の割れ目から生える草・蔦／木の幼木／苔
  - 量：「侵食してるね」と分かる程度・主役にしない
- **車両用入り口の演出**
  - シャッターが開いている状態固定 or プレイヤー到達でアニメーション
  - 暗い内部が見えてる（次シーンへの誘導）
- **CRUSHER との関係**
  - ボスは stage3 だが、ここから建物の影に**CRUSHER のシルエット**を見せて伏線にする選択肢あり
