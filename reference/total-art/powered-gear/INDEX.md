# Powered Gear / Armored Warriors（カプコン, 1994）

**位置づけ：** 今回の SCRAP BLITZ 制作で**一番影響を受けている作品**。トータルアートの最上位リファレンス。

**スタンス：** リスペクト対象であり**模倣対象ではない**。好きだから集めている。エッセンスを抽出して自分流に料理する。

## 参考リンク

- プレイ動画：https://www.youtube.com/watch?v=r-GCEe9iu8E

## 参考にしたい要素

- **ベルスク × メカ題材**の最大の先行例。ジャンルとしての直系
- **重量感のあるメカ操作感**（ダッシュ・ジャンプ・近接の重さ）
- **戦場の密度** — 雑魚が常に画面を埋めて、爆発と弾幕が同居する画面構成
- **メカ撃破時のパーツ飛散・大爆発** — SCRAP THEM!!! 演出の祖先
- **パーツ換装システム** — 本作では「武器パーツ拾い」で機体が変化（SCRAP BLITZ では採用しない設計だが、画面のリッチさは参考）
- **HUD レイアウト** — 画面下端の弾数（VULCAN 50/50 等）表示、左上のキャラ顔/HP
- **ピクセルアートの読みやすさ** — シルエットでメカの種類が瞬時に分かる識別性

## SCRAP BLITZ への落とし込みメモ

- **継承する**：ベルスク × メカの基本骨格、重量感、撃破時のド派手な飛散
- **置き換える**：パーツ換装 → チップシステム + OVERCLOCK（ノイズ最小化のため）
- **強化する**：板野演出（本作の爆発は固定パターン気味、SCRAP BLITZ は曲線軌跡で差別化）
- **モダン化する**：2.5D（Three.js → Unreal）・16:9・現代解像度・Niagara VFX
