# カプコンベルスク 好評意見まとめ（外部リサーチ）

**収集日：** 2026-05-12
**対象作品：** ファイナルファイト / 天地を喰らうII 赤壁の戦い / パワードギア / バトルサーキット
**目的：** 各作の「好評だった点」を拾い、SCRAP BLITZ の楽しさ設計の材料にする

---

## ファイナルファイト（1989）

**ジャンルの神格化された原点として語られる。**

### 拾った好評ポイント

- **「敵を殴ってスカッとする」ただそれだけで面白い**
- **何度プレイしても飽きる気配がない**「無性にプレイしたくてしょうがない」
- ベルスクの礎を築き上げたレジェンド・「面白さはピカイチ」
- 爽快感と操作感の**再現性が高い**
- シンプルな8方向移動と攻撃・ジャンプボタンの**気持ちよいプレイ感**
- ハガーの**掴み技による「大技で敵を粉砕する爽快感」**
- メガクラッシュの**ピンチ脱出**（体力消費で周囲を吹き飛ばす）
- キャラごとの**初心者向け/玄人向けの難易度差**

### 抽出したエッセンス

1. **シンプルな操作系で「殴って気持ちいい」を成立させている**
2. **キャラ選択で難易度と遊び方が変わる**自然な習熟曲線
3. **緊急回避（メガクラ）が体力交換型**——SCRAP BLITZ のメガクラッシュとも親和

---

## 天地を喰らうII 赤壁の戦い（1992）

**「打撃感・SE・ボイス・BGM の総合芸術」として語られる。**

### 拾った好評ポイント

- **敵のリアクション・ボイス・SE による演出の素晴らしさ**
- **必殺技で敵がバラバラに砕ける**視覚的爽快感
- ボス討破時の「**首をはね飛ばしたり、胴体を真っ二つに切り裂く**」満足感
- 大偃月刀で敵を斬る「**ジャキッ！というSE**」の心地よさ
- 敵将撃破時の**「敵将○○、討ち取ったり〜！」という勝利ボイスと拳上げ**
- ザコ敵の「**ぐあっ！と叫びながら倒れて消滅する**」描写
- **BGM が名曲ぞろい**（記者がサントラ購入するレベル）
- つかみ技 → 必殺技のコンボで「**効率よくダメージを与える戦術性**」
- 敵をつかんで投げることで「**複数敵をまとめて制圧する爽快感**」
- 関羽のリーチ・黄忠の高速移動など、**キャラごとのプレイスタイル明確差**
- **複数エンディング**によるやり込み要素

### 抽出したエッセンス

1. **「気持ちよさ」を生んでいるのは打撃のヒット感単独ではなく、SE・ボイス・敵リアクションの総合芸術**
2. **撃破時のスプラッタ性能**（バラバラ・首・胴体）が快感の核
3. **ボス撃破時の固有勝利演出**が興奮を倍化させる
4. **キャラ差は「数値」ではなく「リーチ・速度などの感覚的体験差」で出す**
5. BGM への投資が体験の格を上げる

---

## パワードギア / Armored Warriors（1994）

**「メカで敵をぶっ壊す爽快感」が中核。**

### 拾った好評ポイント

- 本作一番の特徴：**敵の武器を奪い自機に換装してパワーアップ**
- ドリルで敵を貫いたりが「**かなり気持ち良い**」
- ロボットのグラフィックが素晴らしく、**ロボットファンからの評価が高い**
- **敵を破壊する爽快感**が魅力のベルトスクロールアクション
- **協力プレイ時に合体攻撃**を出せる独自要素
- レビュアーが「**基板を買うきっかけとなった思い出の作品**」と述べるほどの没入感
- 難易度は高め（敵の一撃で体力半分以上）——硬派な手応え

### 抽出したエッセンス

1. **「敵を破壊する」の爽快感がベルスクの中心快感**
2. メカ題材ならではの**ぶっ壊す物理的気持ちよさ**（ドリル等）
3. **協力プレイ時の合体攻撃**——SCRAP BLITZ マルチ実装時の参考
4. パーツ換装は SCRAP BLITZ では廃止（ノイズ最小化）だが、**換装が「気持ちよさ」に直結していた**事実は記憶しておく
5. 高難易度＝硬派な手応え（ただしリリース時は AVP の影に隠れた）

## バトルサーキット（1997）

**「キャラ個性の振れ幅」と「コインじゃらじゃら」の爽快感。**

### 拾った好評ポイント

- **使用キャラによってゲーム性が全く変わる**面白さ
- **コインシステム**：敵を倒すとコインが出てパワーアップに使える
- 初心者も「**コインをじゃらじゃら稼げる**」点で爽快感を味わえる
- カプコン製では珍しい**コメディ路線**・ギャグ要素
- それまでのカプコン製ベルスクを知っていれば**元ネタ探しも楽しい**
- ベルスク晩年作の**洗練・完成度**——「豪華なキャプテンコマンドー」
- **隠し要素**による探索の楽しさ

### 抽出したエッセンス

1. **キャラ差を「役割」ではなく「ゲーム性そのものの変化」レベルまで振り切る**選択肢
2. **コインドロップの大量散布が爽快感の主因**——SCRAP BLITZ の「CR大量散乱・チップ少量」原則と完全一致
3. **コインで強化** = ラン中の永続強化要素 = OVERCLOCK 的発想の祖先
4. コメディ・ギャグ路線も成立する（SCRAP BLITZ はシリアス寄りだが、**遊び心は捨てない**指針として）

## 4作横断の共通項

| 共通する好評要素 | 該当作 | SCRAP BLITZ への含意 |
|---------------|------|-------------------|
| **打撃のヒット感** | 全作（特に天地2） | AVP 級ヒット感 × BK4 級テンポの方針と整合 |
| **撃破時の派手な演出** | FF・天地2・パワードギア | SCRAP THEM!!! の方向性と完全一致 |
| **キャラ差** | 全作 | METEO/VIPER/BASTION/CANNON の差別化を「数値」より「感覚」で出す |
| **SE・ボイスの存在感** | 天地2が顕著 | 仕様書で軽視されがちな項目——**実装時に十分な予算配分が必要** |
| **BGM への投資** | 天地2が顕著 | 仕様書「BGM：Suno AI 量産 or 外注」の方針を**最低限維持しつつ、ボス曲だけは予算掛ける**等の差配が有効か |
| **大量ドロップ** | バトルサーキット | SCRAP BLITZ の「CR大量散乱」原則の正当性を確認 |
| **協力プレイ** | パワードギア（合体攻撃） | マルチ実装時の合体技は強い体験になる |
| **緊急回避リソース** | FF（メガクラ） | SCRAP BLITZ メガクラッシュは由緒正しい設計 |

## SCRAP BLITZ への落とし込みメモ

### 強化候補（このリサーチで気づいた、仕様書で薄い領域）

1. **SE・ボイス設計** — 天地2 が示すように、ベルスクの「気持ちよさ」の半分は音響。SCRAP BLITZ の SE 設計はまだ仕様書で詰めていない。**Phase 2.3 以降の優先項目に格上げ候補**
2. **撃破時の固有勝利演出** — 「敵将○○、討ち取ったり〜！」の現代メカ版。ボス撃破時の固定ボイス＋拳上げモーション等。SCRAP THEM!!! の前後演出として組み込み余地あり
3. **キャラ差の「感覚的体験差」化** — 「METEO=バランス／VIPER=軽量／BASTION=重装／CANNON=射撃」という役割定義はあるが、「**リーチ感**」「**速度感**」「**重み感**」レベルまで設計言語化されているか要確認
4. **撃破時のスプラッタ性能** — 「メカをバラバラにする」は SCRAP THEM!!! で実装予定だが、**通常撃破時にも軽いパーツ飛散があると気持ちよさが底上げされる**（パワードギアの破壊感）
5. **キャラごとのゲーム性振れ幅** — バトルサーキットほど振り切らずとも、**「同じゲームを違うキャラで遊ぶ意味」**を強める方向は検討余地あり

### 確認できた既定路線（このリサーチで正当性が裏付けられた）

- ✅ **CR大量散乱・チップ少量原則** — バトルサーキットのコインじゃらじゃらと同方向
- ✅ **キャラごとのガード手段差別化** — FF・天地2・パワードギア・バトルサーキット全てキャラ差を強調
- ✅ **メガクラッシュの体力交換型** — FF メガクラの正統継承
- ✅ **SCRAP THEM!!! 演出** — 天地2 のボス撃破演出と FF の爽快感の現代解として正当
- ✅ **板野演出による派手なエフェクト** — パワードギアの破壊感を 3D + Niagara で強化する方向
