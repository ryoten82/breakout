# 大ボス（ステージボス・最終ボス）

**位置づけ：** Act 末の決戦相手。圧倒的存在感を持ちつつ、**SCRAP THEM!!! 演出**でフェイタリティされる対象。

**親：** [../INDEX.md](../INDEX.md)

## ★最重要方針：ランダム化対応

**Act ボスはランダム化される予定**（memory `project_scrapblitz_boss_randomization.md` 参照）。

- 各 Act に**複数のボス候補**をストックして、ラン開始時に抽選される設計
- → このフォルダには**複数のボスアイデア**を並列で集める
- 仕様書記載の CRUSHER / SNIPER / OVERLORD はあくまで候補の一例
- ボス同士で「役割の被り」がない範囲で、見た目・戦闘スタイルのバリエーションを揃える

## 仕様書からのヒント

仕様書 §17 で挙がっているボス系統：

| 種別 | 特徴 | 候補例（仕様書） |
|------|------|---------------|
| **ステージボス** | 手作り設計・複数フェーズ | CRUSHER（Stage1 候補・大型打撃・部位破壊・2 フェーズ） |
| | | SNIPER（Stage2 候補・距離戦・カバー越し・3 フェーズ） |
| **最終ボス** | Stage 3 末・全要素複合 | OVERLORD（4 フェーズ・AI ネットワーク本体） |

→ 上記はあくまで候補。ランダム化対応で **他のボス候補もここでアイデア出し**する。

## トーン候補

- **圧倒的サイズ感**（プレイヤーの 2〜4 倍以上）
- 雑魚／中ボスとは**明らかに異なる存在**
- **板野演出が映える形状**：突起・噴射口・可動装甲が多い
- **部位破壊／撃破時の崩壊**が前提のシルエット構造
- SCRAP THEM!!! 演出で派手に砕けるパーツ構成

## サイズ目安

- 40〜80m+ （プレイヤー 20m に対して 2〜4 倍以上）
- 最終ボス OVERLORD はさらに大きい or 非実体（ホログラム）の選択肢あり

## ランダム化を見据えた整理

**共通の制約**（どのボスが抽選されても満たすべき要件）：
- ステージ装飾と独立した形状（特定ステージにしかハマらないボスはNG）
- 共通の登場演出（汎用台座リフトアップ等）に乗る作り
- SCRAP THEM!!! 演出のフォーマットに乗る部位構造
- フェーズ移行の見せ方が他ボスと統一可能

**個体差として許容するもの**：
- シルエット・武装・色
- 戦闘スタイル（打撃／砲撃／飛行／重装 等）
- 固有モーション・必殺技

## サブフォルダ構成（案）

ボスごとにサブフォルダを切る運用：

```
boss/
├── INDEX.md          ← この目次
├── crusher/          ← 大型打撃型
│   └── INDEX.md
├── sniper/           ← 距離戦特化型
│   └── INDEX.md
├── overlord/         ← AI 中枢型（最終候補）
│   └── INDEX.md
└── （以下追加候補）
```

→ ボスアイデアが固まったらサブフォルダ追加・命名は英語短縮。
