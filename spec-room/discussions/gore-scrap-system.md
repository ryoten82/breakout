# ゴア・スクラップシステム（仮）

## コンセプト

メカの部位破壊演出。**真っ黒シルエット + オイル飛沫**で、グロ表現を回避しつつ派手さを最大化する設計。

参考イメージ：映画『トランスフォーマー』のメカ解体シーン。
**具体的な内臓表現は好まないので、敢えて真っ黒にすることで「分からないけど派手」を狙う**。

## 雑魚（基本仕様）

### 演出フロー

```
HP 0 になる
   ↓
黒くフェード開始（3〜4 秒・現プレイヤー死亡演出に近い）
   ↓
（A）何もせず → フェード完了で消滅
   ↓
（B）フェード中に殴り続ける
   → 一定確率でパーツがバラバラに
   → 殴った時のパーティクルは黒（オイルイメージ）
   → パーツ分類：頭 / 左腕 / 右腕 / 胴体上半分
   → ダウン確定 → その場で爆発・消滅
   → 各パーツは一回バウンドして消える
   ↓
（C）バーストダウン（lv06 系？大ダメージ？）
   → きりもみ吹っ飛び
   → トレイルでオイルまき散らし
   → 爆散
```

### 重要な設計判断（確定済）

- パーティクル色は **黒**（オイル）
- パーツ分類：**頭 / 左腕 / 右腕 / 胴体上半分**
- バウンド回数：**1 回**
- 黒フェード時間：**3〜4 秒**

## 中ボス以降（雑魚の発展形）

- 基本フローは雑魚と同じ
- **キャラの見た目によって内容を変える**（パーツ構成・破壊順・破片数）
- 一回りリッチな演出（破片数増・トレイル豪華）

## 大ボス（フィニッシャー対象）

- **ここで一番細かくパーツを飛ばす**
- SCRAP THEM!!! フェイズ（§11）の終盤フィニッシュと連動するのが自然
- 関節単位 / 装甲単位など細かい分割

## 実装方針

### Unreal 段階（本番）

- **モデル分断機能（Chaos Destruction / Geometry Collection）を使いたい**
- ユーザー：「どうせ真っ黒なのであまり分からないと思う」→ Chaos の写実度に頼らなくて良いので破壊精度を落とせる
- 代替案として **Niagara で様式化破壊** も検討余地（SCRAP BLITZ の絵柄は Chaos の写実より Niagara の様式化の方が合う場合あり）

### Three.js プロト段階

- 雑魚の敵 mesh が既に複数 mesh で構成されているなら、HP 0 で各 mesh を独立飛翔物体化
- 既存 `dead` ステート枠（救助システムで確保済・memory より）と連携
- パーティクルシステム既存・色設定変更で対応

## 設計の柱との整合

- ❶ 手触り重視・ノイズ最小化：**黒シルエット化は認知負荷を下げる**（具体的なゴアより視覚情報少ない）→ OK
- ❷ 板野思想：オイル散布 + 軌跡 + 爆散 → 本領発揮
- ❹ 技は基本固定：技の挙動は変わらず演出が乗る → OK

## 派生論点（詳細詰めが必要）

### A. ゲーム的判断

1. **黒フェード中の敵の判定**: 殴れる / 殴れない / 殴ってもノーダメ
2. **パーツ吹き飛び確率**: 1 発で 50% / 3 発で確定 等
3. **バーストダウン発生条件**: lv06 攻撃か / 大ダメージか / 両方か
4. **ドロップとの関係**: パーツが飛んだ時に CR / チップが噴出するか・通常死亡と差別化するか
5. **コンボカウンタ**: 黒フェード中の殴りはコンボに含まれるか

### B. 演出のディテール

1. **パーツ別の挙動差**: 頭=爆発 / 腕=回転飛び / 胴体=圧潰 など差別化するか
2. **オイルパーティクルの色味**: 完全黒 / 暗赤黒 / 紫黒
3. **トレイルの長さ・粒数**: バーストダウン時の最大量
4. **サウンド**: メタルクラッシュ系の SE 想定（Phase 3 以降）
5. **画面シェイク**: バーストダウン時に揺らすか

### C. 敵側のバリエーション

1. **中ボスごとのカスタム**: どこまで個別調整するか
2. **大ボス用フィニッシャー演出**: SCRAP THEM 中に発生か / 完了時の最終爆散か / 両方か
3. **ステージごとのオイル色変化**: 環境演出として（例：氷ステージは凍ったオイル）

### D. プレイヤー側との関係

1. **プレイヤーキャラには部位破壊があるか**: 多分なし（被ダメ表現は別系統）
2. **マルチプレイ時のキル帰属**: 最終パーツを飛ばしたプレイヤー / 最終ダメージを与えたプレイヤー

## 私の追加観点

### 1. 「黒シルエット」設計が複数の問題を同時に解く

- グロ回避（生々しさを抑える）
- ストア・配信プラットフォームの年齢制限対応（暴力描写の緩和）
- 全年齢を狙える（海外含めて販路が広がる）
- 制作コスト削減（部位の中身を作り込まなくていい）
- アートディレクションの統一感（メカ題材に映える）

→ 機能的にも商業的にも筋が良い判断。

### 2. トランスフォーマー比較は明確で良い

- 「メカが大量にバラバラ」の絵柄は他のベルスクと完全に差別化される
- ベアナックル系の「人型がダウンする」とは絵的に全然違う
- マーケティング素材（PV）でも一発で個性が伝わる

### 3. Unreal の Chaos Destruction について補足

- Chaos は**写実的破壊**向け（ガラス・コンクリート等）
- SCRAP BLITZ の「黒シルエット + 様式化爆散」は **Niagara の方が向く可能性**
- 関節単位の分断は Skeleton bone hide + 独立 Actor 化でも実現可能
- 「どうせ真っ黒」なら Chaos の精密さは不要 → 実装コストを抑えられる

### 4. 黒フェード時間（3〜4 秒）の調整余地

- 実装後にプレイテストで「次の敵に行きたい時間」とのバランスを取る
- 雑魚密集戦では短く（1.5〜2 秒）/ 単体戦では長く（3〜4 秒）など動的調整も
- 「殴り続ける」インセンティブを生むには、ドロップ量との関係で調整（パーツ破壊するとボーナス CR 等）

### 5. 既存の救助システム dead state 枠と接続

- マルチプレイ救助システム（archive/multiplayer-rescue-system.md）で `dead state` 枠は確保済
- ゴア・スクラップの黒フェード状態はこの dead state を流用 / 拡張できる
- 「救助されなかった味方は爆散する」演出にも展開可能
