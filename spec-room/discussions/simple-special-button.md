# 簡易必殺技ボタン（；キー → **K キー** に変更検討中 / スマブラ式）

## アイデア（ユーザー発言）

> ；キーを簡易必殺技ボタンキーにするかも。
> コマンド入力が苦手な人用、スマブラみたく方向とキー入力だけで出る。
> 懸念としては技自体が足りないところ。

## 構造の整理

スマブラ B ボタン方式 = **中立 / 上 / 下 / 横** の 4 方向で別技。
SCRAP BLITZ に当てはめると：

| 方向 | 出る技（暫定割当） | 既存コマンド版 |
|---|---|---|
| 中立（無方向） | 横必殺技 | `c01_sp_01`（↓↘→+J 波動系） |
| 上+；| 上必殺技 | `c01_sp_02`（↓↑+J 噴射打ち上げ） |
| 下+；| 下必殺技 | `c01_sp_03`（J 長押し 溜めパンチ）※方向と相性微妙 |
| 横+；| 横必殺技 | 中立と同じ？ |

→ 既存 3 種では「中立 / 上 / 下 / 横」の 4 スロットを埋めきれない。**ユーザー懸念「技自体が足りない」が現実的**。

## 想定される選択肢（叩き台メモ・確定じゃない）

- **a. 既存 3 種だけ割り当てる**: 横/上/下に既存技を入れ、空きスロットは空のまま（押しても何も出ない or 通常 J 扱い）
- **b. 簡易版専用に技を増やす**: 4 つ目の必殺技を追加実装（コスト発生）
- **c. 簡易版は方向 3 種類に絞る**: 中立 / 上 / 下 のみで横は廃止（スマブラより簡素）
- **d. キャラごとに必殺技数を増やす設計に変更**: チップで解放される強化版必殺技を簡易版に開放 等（大規模設計変更）

## 派生論点（メモ）

- **コマンド入力勢との均衡**: 簡易ボタンが楽すぎると、コマンド入力する意味が薄れる
  - 解消案：簡易ボタンは威力 -20% / SP コスト +20% 等のペナルティをつける（鉄拳の簡易コンボ的）
  - 解消案：コマンド版のみ「真の必殺技」（演出強化版）が出る差別化
- **キー位置**: J/K/L が右手・；キーは右手のもっと右でアクセス可。パッド側ではどこに割り当てる？
  - パッド：R3 or 既存ボタンとの組合せ？要検討
- **新規プレイヤーの導線**: チュートリアル / オプションで「簡易入力モード」を選べる方が UX 的に親切？常時有効でも OK か？
- **マルチプレイ時**: 片方が簡易、片方がコマンドでも違和感ない設計か

## 私の追加観点

1. **「コマンド入力勢の優越感」をどう設計するか**は意外と大事
   - 完全に同じ威力だと「コマンド入れる人が損」になる
   - スマブラは方向 + B しかないので問題ないが、SCRAP BLITZ は格ゲー寄りなのでバランスが要る
   - 鉄拳 7「アシストコンボ」が良い参考（出せるけど威力減）

2. **「技数不足」は新キャラごとに膨らむ問題**
   - 4 キャラ × 4 方向 = 最大 16 技
   - 既存設計で各キャラ 3 種なら、12 技。中立/上/下/横を埋めるには各キャラ +1 必要
   - **方向 3 種類（c 案）に絞れば既存技数で足りる**ので現実的

3. **「コマンド入力が苦手な人用」のスコープ確認**
   - アクセシビリティ機能なのか / メイン入力方式の置き換えなのか
   - 前者：オプションで切替・デフォルトはコマンド入力
   - 後者：常時両方受付（コマンドも簡易も両方使える）
   - **後者の方が SCRAP BLITZ の手触り重視と整合する**（プレイヤーが自然に好きな方を選べる）

## 次のアクション

- アイデア記録の段階・判断保留
- 必殺技がもう少し増えたタイミング（VIPER 以降の実装時）で再検討
- 別キャラの必殺技設計時に「簡易ボタン込みの 3 種 or 4 種」を念頭に置く

## 第2案：K キーをスマブラ式必殺技ボタンに（2026-05-15 追記）

ユーザー再提案：

> K キーをスマブラ式必殺技ボタンにし、コマンド入力 K にすると強化版が出る、とか。
> 波動、↓↑（もしくは↑↑）、←→（もしくは→→）、↓↓　の４種類。
> 効果の薄い↓K などを必殺技に吸収して意味を足す感じ。
> 色々ゲームを触った感じ、少し技が少ないかもな、とは思ったところ。

### 提案構造

| 入力 | 出る技 |
|---|---|
| K 単独 | 横必殺技（基本・コマンド版より弱） |
| ↑K（or ↑↑K） | 上必殺技 |
| ↓K（or ↓↓K） | 下必殺技 |
| ←→K（or →→K） | ステップ必殺技 |
| コマンド入力 K（↓↘→K 等） | **強化版**（威力・演出増・SP コスト増） |

→ **;キー案を廃して K キーに統合**。第1案より大きな設計変更。

### 既存技との関係（吸収整理）

| 既存技 | 提案後の扱い |
|---|---|
| `c01_atk_l_01`（K 単独・強攻撃） | 横必殺技に吸収？ or 強攻撃として残す？ |
| `c01_atk_l_01_up`（↑K・浮かせ） | 上必殺技に吸収 |
| `c01_atk_l_01_down`（↓K・急降下） | 下必殺技に吸収 |
| `c01_atk_l_01_step`（ステップタックル） | ステップ必殺技に吸収 |
| `c01_atk_l_01_air`（空中 K） | 空中時は別ルート（残す） |

「効果が薄い」と感じた技を必殺技側に格上げして意味を持たせる発想。

### 重要な設計上の判断

**「強攻撃」という概念がどうなるか**が最大の論点：

- **案 X1**: 強攻撃廃止。K = 簡易必殺技 / コマンド K = 強化必殺技 の2層構造
- **案 X2**: 強攻撃残存。K 単独 = 強攻撃 / 方向 + K = 簡易必殺技 / コマンド + K = 強化必殺技 の3層構造
- **案 X3**: 強攻撃を J 系列に吸収（J 長押し / J + 何か）して、K まわりを完全に必殺技専用化

### 技数の試算

| 系統 | 各キャラ技数 | 4 キャラ計 |
|---|---|---|
| 通常攻撃 J（4 段チェーン + 派生） | 約 8 | 32 |
| 簡易必殺技 K（4 方向） | 4 | 16 |
| 強化必殺技（コマンド K・4 方向） | 4 | 16 |
| **計** | **約 16** | **64** |

→ かなり厚い。技数不足懸念は解消方向。

### ユーザー所感「技が少ない」について

実プレイで「技が少ない」と感じたのは正しいシグナル。
DMC・ベヨネッタ・ストⅥなどの現代アクション基準で見ると、現状の **J 4 段 + K + 必殺技 3** は確かに薄い。
本案で **16 技 / キャラ**まで増えれば、現代基準の手応えに近づく。

### 私の追加観点

1. **これは「ストⅡ → スマブラ → 鉄拳 7」レベルのジャンル感の選択**
   - ストⅡ的：コマンドで威力差・コマンド勢の達成感
   - スマブラ的：誰でも出せる・方向が直感
   - 鉄拳 7 アシストコンボ的：両立（出せるけど威力減）
   - **本案は鉄拳 7 寄り**。コマンド入力勢にも報酬、簡易勢にも入口があり、最も穏当

2. **強攻撃の役割が消えると、立ち回りが「コンボ + 必殺技」一辺倒になりがち**
   - 現状の K 単独（強攻撃）は「重い一発」の役割
   - これが必殺技に吸収されると、SP コストの問題で気軽に振れなくなる可能性
   - → **案 X2（3 層構造で強攻撃残存）が安全**かもしれない

3. **入力衝突の懸念**
   - 現状 ↓K は急降下踏みつけ。↓↓ K で簡易下必殺、↓K で急降下、と入力差がシビアになる
   - スマブラは ↓ + B (タメなし即入力) で 1 種類。↓↓ は別アクション（ダッシュ）に振られてる
   - → **入力方式を ↑↑ / ↓↓ にするか・↑ / ↓ 同時押しで判定するか**は慎重に決める必要あり

4. **どこから着手するか**
   - 既存 K まわりの技は全部「Phase 2.2 で実装済」なので、設計変更は実装作業が走る
   - **VIPER 実装時に新方式を導入する** → METEO に逆輸入、の順が安全
   - METEO で先に変えると Phase 2.4 進行中の調整が崩れるリスク

### 次のアクション（第2案分）

- METEO の既存実装に手を入れる前に、紙の上で「強攻撃残存 vs 廃止」を決める
- VIPER 設計時に新方式を試す候補として温存
- 「実プレイで技が少ないと感じた」シグナルは記録しておく → メガクラ・ULT・グラブ含めて再評価する余地あり
