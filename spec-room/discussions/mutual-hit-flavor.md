# 相打ち演出（必殺技 × ボス攻撃のクラッシュ）

## アイデア（ユーザー発言）

> ボスクラスの攻撃に対し、必殺技の判定がちょうど折り重なった時に発生。
> その瞬間に画面ストップ。カメラがズームインしてヒット判定が重なっているところから大量の火花が舞い散る。
> その後、お互いに大きくノックバック、仕切り直し。
>
> 立ち位置としては敵の攻撃無力化なんだけど、狙ってはまず出せない、たまたま時折見れるくらいのもの。
> フレーバーに近い。

## 演出の骨子

```
（プレイヤー必殺技ヒット判定）× （ボス攻撃ヒット判定）が同フレームで重なる
   ↓
画面ストップ（HitStop 拡張）
   ↓
カメラズームイン（重なった判定の中心へ）
   ↓
火花パーティクル大量（板野思想・粒数多めの中央放射）
   ↓
両者大きくノックバック（プレイヤーは後方・ボスも後退）
   ↓
仕切り直し（プレイヤー：硬直解除・ボス：次行動選択へ）
```

## 設計のキモ：「フレーバー」を守ること

ユーザー意図の核心：**狙えると分かった瞬間にフレーバーが死ぬ**。

| 観点 | 「フレーバー」を守るルール |
|---|---|
| 発生条件 | フレーム単位で重なる必要あり（±1〜2F の許容窓推奨） |
| 説明 | UI / 説明書に**書かない**（隠し演出として扱う） |
| 頻度 | セッション中に 2〜3 回見る程度が理想 |
| 報酬 | ダメージ完全相殺（プレイヤー側も無傷）。**経験値・SP・コンボ加算は無し**（稼ぎ防止） |

→ 「あれっ今の何だ」と思わせて、二度目に出会った時に「やっぱりあるんだ」と確信させるのが理想。北斗の合掌 / Bushido Blade の同時斬り系の系譜。

## 確認したい論点

### 1. 対象範囲

- **ボス専用** にするか / **エリート敵の特定攻撃**まで広げるか
- ボス専用だと出会う頻度が極端に低くなる（1 ステージ 1〜2 ボス）
- エリートも含めるとフレーバーとして体験しやすい
- 雑魚も含めると「相打ち稼ぎ」プレイが発生するので不可

### 2. プレイヤー側の対象技

- コマンド必殺技（`c01_sp_01 / 02 / 03`）のみ？
- メガクラ・ULT も対象？（ULT は無敵フラグで相打ち判定回避が綺麗かも）
- 通常攻撃 J / K は対象外（粒数が増えすぎる）

### 3. 演出の長さ

- 0.5 秒程度の短演出 → 「あれっ」感
- 1 秒以上 → 冗長感が出る
- ULT 級の全画面演出は不向き（毎回見ると萎える）

### 4. ダメージ処理

- 完全相殺（推奨・フレーバー設計と整合）
- 半減ダメージ
- 1 だけダメージ
- → 完全相殺が稼ぎ防止と整合

### 5. 演出のクールダウン

- 短時間連続発生を抑制するか（10 秒クールダウン等）
- マルチプレイ時に各 player ごとに独立カウントか

## 既存資産との関係（実装の軽さ）

| 必要要素 | 既存資産 |
|---|---|
| 画面ストップ | `HitStop` システム既存（拡張で対応） |
| カメラズームイン | ULT 演出で実装済（流用可） |
| 火花パーティクル | 既存パーティクルシステム（粒数調整で対応） |
| ノックバック | 既存 `down_chou_*` / `kb_*` 系で流用 |
| 判定重なり検出 | 攻撃判定システムに「同フレーム他判定との衝突」検出ロジック追加（新規） |

→ **実装規模は小〜中**。既存資産の組合せでほぼ実現可能。新規実装は「判定重なり検出」のみ。

## 北極星チェック

- ❶ 手触り重視・ノイズ最小化：頻度低いので問題なし
- ❷ 板野思想：火花放射の絵が本領発揮
- ❹ 技は基本固定：技の挙動は変わらない・特殊演出が乗るだけ → OK
- ❻ マルチ対応：必殺技の主格が明確なら整合（要詳細検討）

## 私の追加観点

1. **「狙えない」を守る最大の敵は良いプレイヤー**
   - ゲームに習熟すると、相打ち発生フレームがメタ化されて狙えるようになる可能性
   - 対策：発生条件を**意図的に難解にする**（必殺技種別 × ボスの特定攻撃 × タイミングの三重条件など）
   - 別案：発生フレーム判定にわずかなランダム性を入れる（±1F の窓が ±0F〜±2F でゆらぐ）

2. **ボス側のリアクションも演出に組み込めると豊かになる**
   - ボスがのけぞる / 蒸気を吹く / 一瞬硬直 → 「あ、ボスも止まったぞ」感
   - ボスのモデルに「相打ち専用ポーズ」を持たせる必要がある（モーション 1 つ）
   - 必須ではないが「いつもより豪華に見える」効果

3. **記憶定着のための「軌跡」演出**
   - 相打ち後、火花が消えたあとも数秒間「判定が重なった軌跡」が残る（薄いライン or グロー）
   - 「あ、あそこで重なってたんだ」と視覚的に分かる
   - スクリーンショット映えする

4. **将来：「相打ち」が SCRAP THEM 中に発生したらどうなるか**
   - SCRAP THEM は時間制限のフェイタリティ演出（仕様書 §11）
   - 相打ちが発生すると SCRAP THEM が中断される？継続される？
   - 「あり得る」状況なので決めておくと良い（多分「相打ち発生しない」が綺麗）
