# コンボ広がりの設計：技数 vs 状況数

## 背景・きっかけ

ユーザーがベアナックル 4 をプレイして気付いた観察：

> 異様にコンボが細かいというか、少ない中で幅を出せていた。

技数自体は 10-15 個程度なのに、戦闘感の幅が非常に広い。これを SCRAP BLITZ にどう活かすかの**設計指針**として残す。

## ベアナックル 4 の「広がり」のからくり

技そのものより、**技が活きる状況**の積み重ねで広がりを作っている：

| 仕組み | 中身 |
|---|---|
| 浮かせ → 拾い → 浮かせ | ほとんどの技に浮かせ属性。壁バウンドで時間稼ぎ |
| 複数敵の位置操作 | 投げで他敵にぶつける / 吹き飛ばしで他敵に当てる |
| HP 消費必殺技 + 回復 | 撃つ → 直後攻撃で HP 戻る。出し所判断が常に発生 |
| スター技の出し所 | 強力だが有限。判断軸を増やす |
| 武器の使い分け | 拾う / 使い切る / 投げ捨て / 拾い続け |
| キャラ間差別化 | 同じ「弱攻撃」でも挙動・リーチが全く違う |

→ **「技数 × 状況数 × 組合せ」で実質バリエーションを作る**戦略。

## 2 つの方向性（設計の二項対立）

技の物足りなさへの対策は 2 系統あり、どちらにも振れる：

### 方向 A：技自体を増やす
- 例：K キー方式（[simple-special-button.md](simple-special-button.md) 参照）/ 新規必殺技追加 / 派生技増設
- メリット：手数が増えて見た目派手・覚える楽しみが増える
- デメリット：技ごとの役割整理が大変・既存設計への影響大・覚える負担

### 方向 B：状況軸を増やす（ベアナックル 4 方式）
- 例：投げを他敵に当てる / 軌道バリエーション / 起き攻め選択肢 / 環境オブジェクト破壊で巻き込み
- メリット：既存技が活きる場面が増える・上達実感が出やすい・北極星と整合
- デメリット：単体プレイテストでは効果が見えにくい（複数敵相手で開花）

## SCRAP BLITZ の現状チェック

| ベアナックル 4 の仕組み | SCRAP BLITZ 現状 | 対応方向 |
|---|---|---|
| 浮かせ → 拾い → 浮かせ | ✅ 空中コンボ実装済 | 維持 |
| 複数敵巻き込み | 🟡 AoE はあるが位置取りこれから | 方向 B 強化候補 |
| HP 消費 + 回復 | 🟢 SP の減少回復で部分実現 | 維持 |
| 武器使い分け | ❌ チップは永続強化で別物 | 検討余地 |
| キャラ間差別化 | ❌ METEO のみ・VIPER 以降で開花 | 自然進行 |
| **投げを他敵に当てる** | ❌ **未実装**（将来課題メモ済） | 方向 B 強化候補 |

## 状況軸を増やすアイデアリスト（叩き台・採用判断は別途）

- **投げを他敵に当てる**: 軌道上の他敵と衝突→両者吹き飛び（既メモあり）
- **投げ方向のバリエーション**: ←/→ で水平投げ・↑ で上投げ・↓ で叩きつけ
- **起き攻めの選択肢**: ダウン中の敵への追い打ち / 起き上がりに合わせた重ね / 立たせ直し
- **環境オブジェクト破壊**: 破壊物の破片に当たり判定・爆発樽の連鎖反応
- **壁バウンド**: ステージ端で吹き飛ばすと壁バウンドして戻ってくる
- **空中軸の追加**: 高高度・中高度・低空での技差別化
- **デッドゾーン技**: 特定の高さ・距離でのみ出る派生技

## 判断指針（設計の北極星補強）

新規技 / 派生技を実装する判断に迷ったら、以下の順で問う：

1. **既存技で似た状況をカバーできていないか？** → カバーできるなら不要
2. **その技が活きる状況は他の技と被っていないか？** → 被っているなら統合
3. **状況軸を増やす方向で代替できないか？** → 代替可能なら方向 B 優先
4. **キャラ間の差別化に貢献するか？** → するなら採用検討

→ 「**技数を倍にする前に、状況数を倍にする**」が SCRAP BLITZ の北極星（手触り重視・技は基本固定）と整合する。

## 直近の優先順（2026-05-15 ユーザー方針確定）

ユーザー方針：

> 壁やられはすでに想定しているので、まずはそっちを本格化するのと、
> 壊れ物などのテスト実装などで広がり検証をすべきかな。

→ **方向 B 先行**で確定。具体的には以下の順：

### 1. 壁やられの本格化（最優先）

既存資産：
- `down_wall_start` (15F) / `down_wall_loop` ステートは実装済（Phase 2.2 で追加）
- `STAGE_LEFT` / `STAGE_RIGHT` のプレイヤークランプは実装済
- プロップカタログで `terr_wall_metal_01` 等の壁カテゴリ定義済（§26.5）

本格化に必要なこと：
- 敵が壁に到達した時の衝突検出
- lv06（超吹き飛ばし）攻撃で敵が壁に張り付く挙動
- 壁張り付き中の追撃可能性（拾い直し）
- ステージごとの壁配置（端壁 / 中間障害物）

### 2. 壊れ物のテスト実装

既存資産：
- プロップカタログの `dest` カテゴリ（§26.5.1）
- ミニマムカタログ 8 個案に `dest_crate_wood_01` / `dest_barrel_oil_01` を含む（§26.5.5）
- §13 経済システムで「破壊オブジェクトから CR」の方針あり

テスト実装で検証したいこと：
- 破壊オブジェクトの挙動（HP・ドロップ・破壊エフェクト）
- 戦闘空間の埋まり感（プロップが置かれることで戦場が「場所」になる）
- 敵を吹き飛ばした時に破壊物に当たって連鎖反応するか
- プレイヤーが壊して新しいスペースを作る戦術が成立するか

### 3. これらを基に複数敵対応を磨く（Phase 2.4 延長線）

- 壁・壊れ物 ＋ 複数敵で「位置取り戦術」が立つかを実プレイで検証
- 投げを他敵に当てる（既メモ済課題）もこの文脈で着手判断

### 4. VIPER 実装でキャラ間差別化を確認

### 5. ここまでで「技が少ない感」が解消されなければ、方向 A（K キー方式）を導入

→ **方向 B を先に深めて、それでも足りなければ方向 A** が SCRAP BLITZ の北極星に最も忠実。

## 設計上の連動チェック

壁やられ + 壊れ物が動くと、以下の既存要素が活きる：

- ✅ `down_wall_*` ステート機械（既実装の出番が来る）
- ✅ プロップカタログ §26.5（最初の実装対象）
- ✅ 経済システム §13（破壊物 CR ドロップが現実化）
- ✅ ドロップ演出方針（CR 大量散乱・チップ少量）
- ✅ ステージ構築ワークフロー（保留中）の判断材料になる（実プロト触ったらワークフロー判断できる）

つまり**壁やられ本格化 + 壊れ物テスト**は、現状の保留事項を多数前進させる起点になる。
