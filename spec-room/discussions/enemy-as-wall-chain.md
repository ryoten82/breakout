# 敵を壁として使うシステム（lv06 吹き飛ばし連鎖）

## 背景・きっかけ

ユーザー発案：

> 壁やられ系はちょっと工夫したいなあ。
> 例えばlv6で吹き飛ばした敵が奥の敵に当たると跳ね上がってさらにコンボがつながる、とか？
> 敵を壁として想定するみたいな感じ。

ベアナックル 4 をそのまま真似ると「壁にぶつかる吹き飛ばし」になるが、それだけだと既存ベルスクの域を出ない。
**「敵自身が一時的な壁になる」**という発想で、SCRAP BLITZ オリジナルの連鎖メカニクスを構築する。

## メカニクスの骨子

### 基本フロー

1. player の lv06 攻撃が敵 A にヒット → A が超吹き飛ばしで飛んでいく
2. A の飛行軌道上に敵 B が存在 → A と B が衝突
3. **B が跳ね上がる**（空中浮かせ状態 = `down_chou_*` 系 or 専用ステート）
4. player は B に対して追撃可能（新コンボ起点）

### 既存「投げ敵による別敵ヒット」との違い

memory の「投げ敵による別敵ヒット」（将来課題メモ・2026-05-14）：

| | memory メモ（既存案） | 本案 |
|---|---|---|
| 起点 | グラブからの投げ | lv06 吹き飛ばし |
| 衝突結果 | **両者ダウン**（伝統的ベルスク式・線的） | **B が跳ね上がってコンボ継続**（拡散的・SCRAP BLITZ オリジナル） |
| プレイヤーの動き | 投げ後の硬直で待つ | 即座に追撃に移行できる |
| 派手さ | 中（2 体倒れる絵） | 高（A は壁役・B から新コンボ・第3敵にも繋げ得る） |

→ 両者は併存可能。**lv06 系 = 拡散連鎖 / グラブ投げ系 = 線的ぶつけ** で役割分担。

### A（吹き飛ばし元）と B（被衝突）の挙動

| 対象 | 衝突時の挙動（叩き台） |
|---|---|
| **A**（飛んでいる敵） | 壁ヒット同様 `down_wall_start` 遷移 or 進行終了 |
| **B**（当たられた敵） | **跳ね上げ**（ホップ vy = 12〜18 程度・空中コンボ可能状態） |
| **C**（B の更に奥にいる敵） | B が C に衝突したら C も跳ね上げ（連鎖継続） |

連鎖深度に上限を設けるか、自然減衰（衝突ごとに vy 80%）で抑えるかは要調整。

## 差別化のポイント

### ベアナックル 4 系との違い

- ベアナックル 4 の「投げをぶつける」は **1 → 1 の線**
- SCRAP BLITZ の本案は **1 → 多 の拡散**（A の軌道上の全敵が連鎖起点になる）
- 結果として「**敵が密集している方が美味しい**」設計になり、北極星の「複数敵活用」と整合

### 板野思想との整合

- 軌道交差で派手な絵
- 敵 A の飛行軌跡・B の跳ね上がり・C の浮き、と多数オブジェクトが連動する画面
- 演出上の見栄えがそのまま機能になっている

### 北極星チェック

- ❶ 手触り重視・ノイズ最小化：状況依存だがランダム性なし → OK
- ❷ 板野思想：軌道演出の本領発揮 → OK
- ❹ 技は基本固定：技の挙動は変わらない・状況が広がるだけ → OK
- ❺ 永続/一時強化分離：本案は基本仕様（強化要素ではない）→ OK
- ❻ マルチ対応意識：複数 player が同時に活用できる → OK

## 実装イメージ

既存実装からの差分：

- `updateEnemies` の knockback 進行ループ内で、`_slamState`（lv06 系で吹き飛び中）の敵 A について他敵との衝突判定を追加
- 衝突検出時：
  - A の挙動: `down_wall_start` 強制遷移 or 速度ゼロ化
  - B の挙動: `bumpCombo` 呼びつつ B 用の浮かせ dispatch（既存 `down_chou_start` 系を流用 or 専用新ステート）
- player のコンボカウンタ：A → B 連鎖は同一コンボとして継続（lastHitEnemy 追跡）

→ 実装規模は**中程度**。既存ステート機械の延長で実現可能。新規ステートはオプション（最初は既存流用で動かして体感確認）。

## 派生論点・調整パラメータ

- **衝突判定範囲**: A と B の距離どこまでで衝突認定するか（X / Z / Y それぞれの許容幅）
- **連鎖深度**: A → B → C → ... の最大深度。3 段 or 無制限 or vy 減衰任せ
- **角度依存**: A の進行方向によって B の跳ね角度を変えるか（横ヒット = 横飛び / 斜め = 斜め飛び）
- **damage 伝播**: A 自身の damage が B に乗るか・別途固定値か
- **A のダメージ**: B にぶつかった A はダメージを受けるか（伝統的にはダメージあり）
- **CR / チップドロップ**: 連鎖巻き込みで倒れた敵のドロップは player 側に確実に来るようにする
- **多人数 player 時**: lv06 を撃った player のコンボに帰属させるか・最終ヒット者に帰属させるか

## 戦略的価値（プレイヤー視点）

- **密集している敵を見つけたら lv06 を撃ち込む**動機が生まれる
- **囲まれた状況がチャンスに変わる**（孤立した敵より美味しい）
- 板野思想の演出が「映え」だけでなく「実利」と結びつく
- 上級プレイの目標になる（密集敵への lv06 ヒット → 連鎖最大化）
