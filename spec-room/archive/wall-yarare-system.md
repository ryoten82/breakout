# 壁やられシステム（衝突先別の挙動）

## 背景

lv06（超吹き飛ばし）攻撃で吹き飛んだ敵が何かに当たった時、**衝突先の種類によって挙動を分ける**設計。ベアナックル 4 の「壁ぶつけ」をそのまま真似ると差別化が弱いため、衝突先 3 種で異なるリアクションを設計。

## 確定した挙動（2026-05-15）

ユーザー方針（物理直感ベース）：

> 壁は完全に壊れないので衝撃が逃げないから、こっちにバウンドして帰ってくる、もしくはビタッと張り付く（最初の想定はこっち）。
> 敵や壊れ物に当たった場合は敵が吹き飛ぶ関係で上に跳ね上がる軌道になる。

### 衝突先 3 パターン

| 衝突先 | 物理的解釈 | 飛んでいた敵 A の挙動 | 衝突先の挙動 |
|---|---|---|---|
| **壁**（不動・terr_wall 系） | 反作用が全部 A に返る | **張り付き**（既定）or バウンド | 影響なし（不動） |
| **他の敵**（B） | A の運動量が B に伝わる → 両者上向きへ | A は速度低下・落下開始 | **B が上に跳ね上がる**（空中コンボ起点） |
| **壊れ物**（dest 系） | 同上（質量小さい想定） | A は速度低下・落下開始 | **壊れ物が上に弾けて破壊**（破片・ドロップ放出） |

### 壁衝突の詳細（既定：張り付き）

- `down_wall_start`（15F）→ `down_wall_loop` の既存ステートを活用
- A は壁に張り付いた姿勢で停止（X 速度ゼロ・Y は重力に従う or 拘束）
- 一定 F 後に剥がれて落下開始
- **拾い直し可**（player が追撃すれば dispatch list に再エントリ）

→ バウンド挙動（壁にぶつけて跳ね返り）はオプション扱い。最初は張り付き優先で実装し、必要なら後で切替パラメータを追加。

### 敵衝突の詳細（拡散連鎖）

- A の knockback 進行中に他敵 B との衝突を判定
- 衝突時：
  - **A**: `down_wall_start` 相当の挙動（速度ゼロ化・短い硬直）or `down_chou_loop` で進行終了
  - **B**: 跳ね上がり → `bumpCombo` でコンボ継続・空中コンボ可能状態（既存 `down_chou_start` 系 or 新ステート）
- B が更に C と衝突したら C も跳ね上げ（連鎖深度は要調整）
- player のコンボカウンタは lastHitEnemy 追跡で自動継続

### 壊れ物衝突の詳細

- A の knockback 進行中に dest 系プロップとの衝突を判定
- 衝突時：
  - **A**: 敵衝突と同じく速度低下・落下開始
  - **壊れ物**: 破壊エフェクト発生・破片パーティクル + ドロップ（CR / チップ）放出
- 壊れ物は「動かない壁ではない」が「跳ね上がる対象でもない」→ **破壊して消える**役割
- 結果として戦闘空間が動的に変化していく

## 設計上の差別化ポイント

### ベアナックル 4 / Final Fight 系との違い

- ベアナックル 4：壁ぶつけ = 1 体ダウン（線的）
- SCRAP BLITZ：
  - 壁 = **張り付き**（コンボ継続起点）
  - 敵壁 = **拡散連鎖**（密集敵が美味しい設計）
  - 壊れ物 = **破壊 = 戦場変化**

→ 衝突 1 つでも結果が 3 通りに分かれる = 状況軸の幅が広がる（[combo-depth-axis.md](combo-depth-axis.md) の方向 B 実例）。

### 板野思想との整合

- 軌道交差で派手な絵
- 複数オブジェクトの同時連動（A 飛行 → B 跳ね上がり → 壊れ物破壊 が連鎖）
- 演出が「映え」と「実利」を同時に満たす

### 北極星整合

- ❶ 手触り重視・ノイズ最小化：状況依存だがランダム性なし → OK
- ❷ 板野思想：本領発揮 → OK
- ❹ 技は基本固定：技の挙動は同じ・状況が広がるだけ → OK

## 実装規模見積

| 項目 | 規模 | 既存資産 |
|---|---|---|
| 壁衝突（張り付き） | 小 | `down_wall_start` / `down_wall_loop` 既実装・あとは collider 接続 |
| 敵衝突（拡散連鎖） | 中 | knockback 進行ループに衝突判定追加・既存 `bumpCombo` / `down_chou_start` 流用 |
| 壊れ物衝突 | 中 | プロップカタログ §26.5 の dest 系初実装と同時着手 |
| **合計** | **中程度** | 既存資産を大量に流用可能 |

## 派生論点（実装時に判断）

- **衝突判定範囲**：X / Z / Y それぞれの許容幅
- **連鎖深度**：A → B → C の最大段数 or vy 減衰任せ
- **角度依存**：A の進行方向で B / 壊れ物の弾け方向を変えるか
- **damage 伝播**：A の damage が B / 壊れ物に乗るか・別途固定値か
- **A 自身のダメージ**：衝突した A は被ダメージするか（伝統的にはあり）
- **CR / チップ帰属**：連鎖巻き込みドロップは lv06 撃った player に帰属させるか
- **多人数 player 時**：コンボ帰属の扱い
