## ① コンセプト：Act 1 大ボスとして何を体験させたいか

### Claude 叩き台

**「Act 1 を通して学んだ操作の全部入りテストとして機能する大ボス」**：

- これまで雑魚 / midboss01 で学んだ要素を全部使わせる（コンボ・空中攻撃・必殺技・回避・ガード）
- ただし「複雑な読み合い」よりも「**大きさと派手さの圧で気持ちよく崩す**」体験を優先
- 部位破壊で「ここを狙え」が視覚的に分かる
- Phase 3 必殺技で初めて「リパルスカウンター」の存在を提示（学習トリガー）

### 議論ポイント

- 「学習トリガー」として何を新規教えるか（リパルスカウンター以外に？）
- midboss01 との差別化軸（midboss01 = 盾＋berserker / 本ボス = ？）
- 「Act 1 大ボス」と「テンプレ第1弾」の両立 — 後続 Act2/Act3 大ボスにそのまま転用できる構造か

### 決着（✅ 2026-05-24）

**① コンセプト方向性 — 確定事項**

- **midboss01 との差別化軸**
  - 動きは遅い・振りも大きい（重量感）
  - **完全スーパーアーマー持ち**：特定の行動を突かなければ一切よろめかない（midboss01 の SA=2・active 限定とは段違い）
  - 判定がとにかく広く、**AOE 攻撃が多彩**
  - **フェーズ転換でどんどん激しくなる**（同じ攻撃のバリエーション増・発生短縮）

- **学習トリガー設計**
  - 主に **AOE 攻撃のパターン**を学ばせる
  - **Phase 1 で出方を覚え、Phase 2/3 では同じ攻撃の発展形を捌く**
  - 新規攻撃を後半で大量投入せず、「**早くなる・増える・重なる**」で激化を表現
  - Phase 3 必殺技（リパルスカウンター対象）は別枠の新規学習トリガーとして 1 種のみ追加

- **学習体験の流れ**
  - Phase 1：3 種 AOE をゆったり提示 → プレイヤーがパターンを掴む
  - Phase 2：同じ 3 種 + 派生 1-2 種 / 発生短縮・連打化
  - Phase 3：すべて + 必殺技 1 / さらに激化 + リパルスカウンター学習

→ **「ボスは難しくない、速くなるだけ」**という設計思想。学んだものが活きる達成感を最優先。

## ② メカ構成・サイズ

### Claude 叩き台

| 項目 | 提案 |
|---|---|
| サイズ | **400wu（80m）** — プレイヤーの 4 倍。画像参照で確定 |
| 脚部形式 | **2 脚（直立人型）**：画像のシルエット準拠。動きは遅く重い |
| 主武装 | 両腕に大型クラッシャー / 肩部にランチャー or 砲塔 / 胸部 or 腹部にコア |
| 部位破壊 | 左腕 / 右腕 / 肩ランチャー の 3 部位（候補） |
| 撃破時崩壊 | 左肩 → 右肩 → 胸部コア露出 → SCRAP THEM!!! へ |
| 完全 SA | 通常時すべての攻撃でよろめかない。**特定行動**（リパルスカウンター成功 / 部位破壊 / Phase 移行）でのみ崩せる |

### 代替案

- **A. 4 脚多砲塔型**：移動遅・area_denial 強・部位破壊 4-6 個（重厚／実装重い）
- **B. 2 脚 + ホバー（叩き台）**：機動と威圧の両立／実装軽い
- **C. 履帯重戦車型**：シルエット重・全身が砲塔／陸戦感強いが「大ボス」の派手さに欠ける

### 決着（✅ 2026-05-24）

**② メカ構成 — 確定事項**

| 項目 | 確定 |
|---|---|
| サイズ | **400wu（80m）** — プレイヤーの 4 倍。画像参照 |
| 脚部形式 | **2 脚直立人型** |
| 完全 SA 崩しトリガー | ①**リパルスカウンター成功時** ②**ULT 命中時**（試験的追加・効果は調整） ③**特定の隙が大きい大技**実行中（リアクション大きめ） |
| 部位破壊 | **やらない**（リソース集中・先細りを回避） |
| 外殻破壊 | やりたいがリソース都合で見送り |
| 演出集約先 | **SCRAP THEM!!! フェイタル**に全て寄せる |

**SA 崩しトリガーの設計補足**：
- **リパルスカウンター成功**：Phase 3 必殺技を弾いたとき、確定クリ + 100% gc + 大ダウン
- **ULT 命中**：仕様試験中。ボス専用挙動として「ULT 命中時はリアクション大きめ + 短ダウン」を仮置き
- **大技中の隙**：特定 1-2 種の大技に「recover が長く、リアクションも大きい」設定。プレイヤーが見切って差し込む読み合い枠

## ③ Phase 別攻撃カタログ（命名規則 `boss1_atk_NN`）

### 決着（✅ 2026-05-24 / 仮配置）

**方針**：「Phase 1 で学んだ AOE を、Phase 2/3 で早く・連打されながら捌く」+ Phase 3 で RC 対象必殺技 + RC 対象外大技を追加。

#### Phase 1（HP 100% → 60% / 基本 3 種 AOE）

| ID | 名称 | モチーフ | 距離 | atklv | 備考 |
|---|---|---|---|---|---|
| `boss1_atk_01` | クラッシャー振り下ろし | 縦薙ぎ AOE・近〜中距離 | 短〜中 | lv4 | 予兆長め・回避猶予あり |
| `boss1_atk_02` | 横薙ぎなぎ払い | 横振り AOE・広範囲 | 中 | lv4 | 横幅広い・ジャンプ回避推奨 |
| `boss1_atk_03` | 地響き衝撃波 | 地面叩き → 円形衝撃波 AOE | 近〜中 | lv5 | 設置型 AOE・距離取って回避 |

#### Phase 2（HP 60% → 20% / 同 3 種高速化 + 派生 1）

- `boss1_atk_01-03` を**発生 -20% / cooldown -25%**（連打感）
- + `boss1_atk_04`：派生攻撃 1 種
  - 候補 A：**二段薙ぎ払い**（atk_02 の延長・横振り 2 連）
  - 候補 B：**広域踏みつけ**（atk_03 の延長・衝撃波 2 連）

#### Phase 3（HP 20% → 0% / + RC 必殺 1 + RC 外大技 1）

- Phase 1/2 全攻撃をさらに高速化
- + `boss1_atk_05`：**RC 対象 必殺技**（暫定名：CRUSHER STOMP）
  - 大ジャンプ → 落下叩きつけ → 全画面衝撃波
  - 弾き成功 = 確定クリ + 100% gc + 完全 SA 崩し
  - 弾き失敗 = 大ダメージ + ダウン
- + `boss1_atk_06`：**RC 対象外大技**（暫定名：DOUBLE RUSH TACKLE）
  - **溜め動作**（wind 長め・大きく予兆）→ **現在位置の反対側 画面端までタックル突進**
  - 反対端到達 → **振り返り → 再度反対端までタックル**（= 計 2 往復）
  - 完了後 **大きな recover 硬直**（SA 崩しトリガー対象・反撃の最大チャンス）
  - 1 往復目・2 往復目とも当たり判定持続。プレイヤーは横軸（画面端方向）の回避とジャンプ抜けが要求される
  - atklv：要調整（突進系は lv5 想定）

### 配置調整余地（🟡）

- Phase 3 は HP 20% で戦闘時間が短い → `boss1_atk_06` を**実は見られない**懸念
- **対応案**：戦闘テスト後、見られない場合は Phase 2 に格上げ（Phase 2 派生攻撃を atk_06 に変更）
- 実装時に Phase 2 / Phase 3 のどちらに置くか試験で決定

## ④ HP 配分

### Claude 叩き台

| 基準 | 値 |
|---|---|
| midboss01 HP | **300**（spec 値・実装は 250 暫定） |
| 本ボス目安 | **3 分戦闘** = midboss01（20 秒）の 9 倍時間 |
| 倍率仮置き | midboss01 × 6（= 1800）または × 9（= 2700） |

Phase 別配分（**40/40/20**）：

| 配分 | HP 仮値（1800 ベース） | HP 仮値（2700 ベース） |
|---|---|---|
| Phase 1 (40%) | 720 | 1080 |
| Phase 2 (40%) | 720 | 1080 |
| Phase 3 (20%) | 360 | 540 |

**HP ゲートで境界 1 残し**：
- Phase 1 終了 HP = 1080 (1800 ベース) → ここで必ず停止しメガクラ
- Phase 2 終了 HP = 360 (1800 ベース) → ここで必ず停止しメガクラ
- Phase 3 → 0 で撃破

### 決着（✅ 2026-05-24）

**HP 仮値 = midboss01 × 6 = 1800**（3 分戦闘ライン）

| Phase | 配分 | HP |
|---|---|---|
| Phase 1 (40%) | 1080 → 720 | 360 削り |
| Phase 2 (40%) | 720 → 360 | 360 削り |
| Phase 3 (20%) | 360 → 0 | 360 削り |

- **HP ゲート**：1080 / 360 で必ず 1 残してメガクラ発火
- 🟡 実 DPS は後日計測 → midboss01 を複数回討伐し平均 DPS を取得 → 確定値へ調整

## ⑤ escort / 取り巻き

### Claude 叩き台

**本ボスは単体出現**（midboss01 までで取り巻き戦は十分体験済）。
ただし Phase 2 突入時の演出として、**雑魚 2-3 体が「援軍」として落下スポーン**するパターンを 1 回だけ入れる選択肢あり：
- leaderless 演出は本ボス撃破時に発動（援軍残党が逃げる）
- 性格は brave 寄り（CRUSHER のスタイルに合わせる）

### 決着（✅ 2026-05-24）

- **実装テスト時**：**単体出現**（1on1 集中・スタブの確認に専念）
- **本実装時**：**フェーズ単位で増援投入**を入れたい
  - Phase 2 突入時 or Phase 3 突入時に雑魚 2-3 体落下スポーン
  - 性格は brave 寄り（CRUSHER のスタイルに合わせる）
  - leaderless 演出：本ボス撃破時に援軍残党が逃走
- どのフェーズで投入するか、何体投入するかは本実装時に試験で決める（🟡）
