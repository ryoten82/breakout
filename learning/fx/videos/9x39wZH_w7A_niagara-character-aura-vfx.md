## 概要

前作で作った「シンプルなオーラ」は見た目が単調だったため、マテリアル側のシェイプマスク多層化・WPO（ワールドポジションオフセット）調整・リフラクション追加・エミッシブの二値化により質感を強化し、Niagara 側では同一システムを複製して2層のオーラエミッタを異なる速度・アルファ・スケールで重ねる、という構成強化編。全体を通して「キャラを包むスフィアメッシュ + ノイズテクスチャベースのマテリアル」という土台は前作と共通で、そこに追加ノードを積み上げていく設計。

## マテリアル構築（シェイプマスク）

1. ベースは前作と同じノイズテクスチャ。**2つの複製シェイプ**を作り、それぞれ異なるタイリング/スケール/パンナーで変化をつける
2. シェイプ1: U タイリング=2、UV オフセットでランダム性を追加、Dynamic Material Parameter（DMP）× Time でパンナー速度を制御。さらに Distort（簡易歪み）と中心からのスケール拡大を適用
3. シェイプ2: タイリング・スケールなしのデフォルトのまま。ただし**値を弱める**（intensity を下げる）
4. **2つのシェイプを同じ強さで足すと単調になる**ため、意図的に強弱差をつけてから加算するという設計判断が明言される（"these shapes with the same value is bad"）
5. 加算結果を **Linear Gradient と乗算**してシェイプマスク完成

## WPO（ワールドポジションオフセット）

- ノイズテクスチャ × **Vortex Normal（World Space）** で歪み方向を決定
- それを **Linear Gradient と乗算**して、材質の下部（脚部分）に WPO がかかりすぎないよう抑制。「脚のオーラが歪みすぎる」問題への対策として、グラデーションマスクで WPO 強度自体をフェードさせる、という具体的な対処法が語られる
- WPO の強さの違いで見た目の印象が大きく変わることが実演され、"most important part" と強調される

## オパシティ

- シェイプマスク × **Fresnel**（エッジの滑らかな遷移）× Particle Color のアルファチャンネル + 追加の2マスク（シェイプの表示範囲を中心に収めるための補助マスク、テクスチャ or ノードで作成）× **Depth Fade**

## リフラクション（既存ドクトリンに未収録の要素）

- WPO で使ったノードを再利用し、**×4** して値を持ち上げ、範囲を1に近づけるようクランプ
- **Lerp でリフラクションの強度を制御**するというシンプルな構成

## エミッシブカラー

- シェイプマスクの値は小さいため **×200 してから 0〜1 にクランプ** → ソフトなマスクを明瞭な色の境界線（"clear color distinction"）に二値化する
- 二値化したマスクに **グラデーション**を持たせ、**Saturate（LDR 入力）+ HDR tint** を分離して用意
- 色の強度は **DMP で外部制御**、最終的に shape mask 出力値・Particle Color と乗算して仕上げる

## Niagara 側の構成（2層オーラの重ね方）

- 前作の Niagara システムを複製し、新しいマテリアルに差し替え
- 基本設定は変更不要。**Particle Update の Scale Color / Scale Mesh Size / Dynamic Material Parameters のみ**調整する運用
- **Scale Mesh Size の Z 軸を 1.5** に設定してキャラ全体（頭上まで）を覆うようにする
- 1層目: Scale Alpha = 0.5、パン速度用 DMP を 1→2 に変更
- 2層目（複製・別パラメータ）: 速度を 1→2、Scale Alpha = 0.2（1層目より弱く、下地として重ねる）、サイズは基本据え置き（範囲が広すぎる場合は 0.6 等に調整）
- オーラのサイズは **User Parameter で外部公開**し、システム単位で調整可能にしている

## 新規性のある技術情報（既存ドクトリンとの比較）

`fx_technique_doctrine.md` の「キャラ付随」節はボーン追従の capsule パーティション方式（"各ボーンに手動でカプセル寸法をマッピングする力技"）を全身グローの主手法として挙げているが、以下は未収録で新規:

- **スフィアメッシュでキャラ全体を包み、スフィア UV ベースでマテリアルを組む**という全身オーラの代替アプローチ（capsule パーティションより単純だが、キャラの体型に沿わせる精度は落ちるトレードオフがある）
- **同一ノイズテクスチャを複製し、強弱を意図的に変えてから加算する**という「均等な強さで重ねると単調になる」という失敗パターンの明示（マスク合成の具体的な設計判断として新規）
- **WPO 強度自体を Linear Gradient でフェードさせ、脚などの意図しない部位の歪みすぎを抑える**という WPO 特有の抑制テクニック（doctrine の「グロー勾配」節とは別軸、WPO の強度制御に特化）
- **リフラクション**（既存ドクトリンに項目自体がない）: 既存ノード再利用 ×4 → クランプ → Lerp で強度制御、という軽量な追加手法
- **エミッシブの二値化パターン**: シェイプマスク値を大きく乗算してクランプすることで「ソフトなノイズマスク」を「明瞭な色の境界」に変換し、そこにグラデーション + LDR(Saturate)/HDR tint を分離適用する設計（doctrine の「RGB を白 1px に差し替え色を分離」とは異なる、ソフトマスクの二値化という別パターン）
- **2層エミッタを速度・アルファ・サイズだけ変えて重ねる具体的な数値例**（0.5/1→2 と 0.2/1→2 のペア）が、doctrine の「層分け」原則の実装レベルの一例として得られた

## SCRAP BLITZ UEへの応用メモ

- SP 技発動中・覚醒状態のキャラオーラ演出に直結する内容。特に**リフラクション追加**は既存の OC ジェムや魔法系エフェクトにない質感を安く足せる可能性がある（既存ノード×4→クランプ→Lerp という軽量構成のため、既存マテリアルへの追加コストが低い）
- **2層オーラ重ね（速度差+アルファ差+サイズ差）**は、SP ゲージ満タン時の「気を纏う」演出などに転用しやすい。1層目を強く速く、2層目を弱く遅く重ねることで単層より複雑な見た目が安価に作れる
- **WPO の脚部フェード抑制**は、2.5D 固定カメラでもキャラの接地感を崩さずにオーラを揺らめかせる際に有効。SCRAP BLITZ UE のプレイヤー/ボスは capsule 半径が個体差あり（boss half 288 vs 90 等、CLAUDE.md 座標変換規約参照）なので、Linear Gradient のフェード開始位置はキャラごとに調整が必要になる可能性がある
- **エミッシブ二値化（×200→クランプ）**は、コンボ/BURST 化時の「輪郭が急に明瞭になる」演出パラメータとして使える。DMP で intensity を外部制御する構成のため、SP 消費順序や BURST 発動タイミングに合わせてリアルタイムに輪郭の鋭さを変化させる用途に転用できそう
- スフィアメッシュで包む方式は、既存の capsule パーティション方式と比べて実装が単純な分、キャラの手足のシルエットには追従しない。プレイヤーキャラのような手足の動きが激しいモデルより、ボス/敵の「纏う靄・オーラ」のような大まかな輪郭で足りる演出に向く可能性がある
