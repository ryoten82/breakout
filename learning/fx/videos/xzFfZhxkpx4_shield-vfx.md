## 概要

キャラクターに追従するシールドの**完全なライフサイクル**（出現エフェクト→常駐ループエフェクト→終了時の破壊エフェクト→アクティブ中の被弾エフェクト）をNiagaraだけで組む実践動画。メッシュはEpic配布の六角形（hex）ライク球状メッシュ2種、マテリアルも既製の2種（通常時用・破壊時用）を使い、動画の力点はマテリアル制作ではなく**Niagara Systemの構成・Emitterの複製差分・Dynamic Material Parameterの時間制御・ループ中の回転値継承計算**に置かれている。最後にLevel Blueprintでキャラクターアニメーションと同期させて実演する。

## 技術詳細（構築順）

### 1. 前提アセットとDynamic Material Parameter（4種）[00:25]-[03:06]
- メッシュ2種（通常用・破壊用）、マテリアル2種（通常時=impact、破壊時=break）はEpic配布アセットをそのまま使用。マテリアル自体の作り方には踏み込まない
- マテリアル側が公開する Dynamic Material Parameter は4つに整理されている。これがNiagara側でシールドの全状態を制御する主軸になる：
  - **Distort Amount**：屈折（リフラクション）量。控えめが良いとされる
  - **Sphere Fade**：hex内部の色の強さ。上げると内部の色・アニメーションがフェードして見えなくなる
  - **Hex Boost**：エッジの発光（emissive）強度
  - **Brake Power**：破壊度合い。上げるほど内部が消えていき、カーブで制御すると破壊アニメーションになる

### 2. Emitter「Open」＝出現エフェクト [03:06]-[06:25]
- Mesh Renderer、Life Cycle Mode=Self、Spawn Burst Instantaneous（一度きり出現）
- Spawn Count=3（複数メッシュを同時スポーンし、サイズをランダム化してバンプオフセット的な重なり感を出す。メッシュサイズは1.2〜1.5のランダムレンジ。差を大きくしすぎない）
- Lifetime：0.2〜0.3のランダム
- Color：User Parameterで外部化（デフォルト青）→レベル側で調整可能にする定型パターン
- Initial Mesh Orientation：Z軸回転、速度0.1（速すぎると不自然になるため抑える）
- Scale Color：0〜5のFloat Curveで、出現・拡大時に明るく、消える時に暗くフェード
- Scale Mesh Size：Uniform Curveで1→1.1のわずかな拡大（ここをVector化すれば3軸個別スケールで円形シールドを楕円に変形できる、と言及）
- Scale Mesh SizeはUser Parameterでも制御し、レベル側からシールド全体のサイズを変更可能にする
- Dynamic Material Parameterのカーブ設定：
  - Distort Amount：Scale Colorと同じカーブインスタンスを流用
  - Sphere Fade：開始1.0→key0.2で0.5→終端0.4（消滅後も内部の質感を少し残す狙い）
  - Hex Boost：開始0→key0.1で10〜50に急上昇→その後緩やかに減衰（生成直後だけ強く光らせ、すぐ弱める）
  - Brake Power：出現エフェクトでは破壊不要のため一定値1に固定

### 3. Emitter「Loop」＝常駐エフェクトと回転継承計算 [06:25]-[10:19] ★本ノートの核心
- まずOpenを複製して「Transition」（Spawn Count=1・Lifetime=1・Mesh Sizeを固定値化した中間段階）を作り、次にそれをさらに複製して「Loop」を作るという**2段階の差分複製**で作業を進める
- Loopの鍵は **Loop Behavior = Multiple**（1回きりでなく複数回スポーンする設定）。スポーン回数はInteger型User Parameter「Count」で外部制御（例：3回、1秒ごと）
- **Loop Delay**：出現エフェクトと同時に常駐ループが始まると不自然なため、出現→常駐への遷移が終わるタイミング（0.5〜0.6秒）までLoopの初回スポーンを遅延させる。ただしこの遅延は**初回ループのみ**に適用され、2回目以降は通常どおり1秒間隔でスポーンする
- Scale Colorは出現エフェクトと異なり、常駐中は消えてほしくないため開始値0.5・終了値0.5で固定し、常時視認できる状態を維持する
- **回転値の継承問題**：各ループのスポーン毎にパーティクル回転が初期値へリセットされてしまい不自然に見える。これを解消するため Initial Mesh Orientation（Z軸のみ、Make Vectorで構築）に**前段階からの回転値を引き継ぐ計算**を追加する：
  1. Transition Emitterの最終回転値を近似する定数を求める（Lifetime=1×Rotation Speed=0.1で理論値0.1になるが、Scale Colorでフェードアウトするため終端付近はほぼ見えない＝実際の見た目に寄与する回転量は0.1よりやや少ない0.05〜0.06程度で妥協、と明言。厳密計算は不要と割り切っている）
  2. Loop自身の初期回転オフセットは **Multiply Float by Int**（回転速度0.1 × Emitter Loop Count＝そのループが何回目のスポーンかを表すNiagara組み込み値）で算出し、ループが進むごとに回転が正しく積算されるようにする
- この「**Emitter Loop Countをintソースとして使い、経過ループ回数に比例した値を都度計算する**」パターンは、時間ベースのカーブでは表現できない“ループ跨ぎの連続性”を解決する具体策として新規性が高い
- Dynamic Material ParameterはScale Colorと同型のカーブ（0→1→0）をDistort Amountに流用、他はデフォルト値（0.5, 0.1, 0）で固定
- Scale Mesh Sizeは一定値または**Sign関数**でより動的なサイズ変化を作ることも可能、と言及（詳細な実装は割愛）

### 4. Emitter「Break」＝破壊エフェクトとスポーンタイミングの手計算 [11:07]-[14:09]
- Loopを複製し、マテリアルのみBreak用に差し替え。Life CycleはSelf/Onceに戻す
- **Loop Delayを使わず、Spawn Burstの発火タイミングを直接数式で指定**する方式に切り替える理由が明示される：Break開始タイミング＝「Loopの初回遅延（0.5秒）＋Loopの総継続時間」。Loopの総継続時間は Lifetime=1秒 × スポーン回数（Count）で近似できるため、Countパラメータをそのまま秒数として加算に使える、という設計判断
- Lifetime：0.3〜0.5のランダム（Openより長め）、Mesh Sizeもランダム化
- Scale Mesh Size：1→2に拡大し破壊感を強調
- Mesh回転：Openでは一定速度回転だったが、Breakでは完全なシールド形状を見せる必要がないため**ランダム回転**（各軸0.1〜0.2程度のランダム値）に切り替え
- Dynamic Material Parameter：
  - Sphere Fade：0→key0.2で0.5→key1.0で0.4（Open同様の設計）
  - Hex Boost：key0.1で高い値（0.02※推定、字幕の数値は信頼度低）→key0.2にかけてゼロまで減衰
  - **Brake Power**：0→key0.05で2→key0.8で20と大きく上げる。これが破壊（shatter）演出の主要因子であると明言
- **Loop Durationの設定漏れに気付き途中で追加修正**する場面あり：Niagaraはこの値の範囲内でしかパーティクルをスポーンしないため、Delay設定を0.5→1に複製・修正して正しく発火するようにした、という実演上の教訓（=Loop DelayとLoop Durationは別パラメータで、片方だけ設定すると発火しない罠）

### 5. 被弾（Impact）エフェクト＝独立Niagara System＋4方向配置 [14:36]-[19:16]
- 被弾エフェクトは発生タイミングを予測できないため、シールド本体のSystemに混ぜず**別のNiagara System**として作る設計判断が明言される
- Openを複製したEmitter＋部分的なhexメッシュを使う新規Emitterの2本構成。マテリアルは両方ともimpact用を使用
- メッシュサイズをやや大きめ（1.3〜1.5）にし、Scaleで衝撃時に一度膨張してから収縮させる「テンション」演出（key0.05で1.25→key0.1で1.05→1.0へ収束、というカーブ形状）
- **4方向配置のための Return Exec Index 活用**：Initial Mesh Orientation（Z軸）で `Return Exec Index × 0.25` を使うと、パーティクルのスポーン順インデックス（0,1,2,3）がそのまま 0°/90°/180°/270° の回転値に変換される。Spawn Count=4と組み合わせるだけで放射状4方向の配置が完成する、という簡潔な実装
- **球面上に配置する位置計算**：Multiply Vector by Float で「パーティクルのMesh Orientationベクトル（X軸）× 中心からの距離（Float、User Parameter化してシールドサイズにも連動）」を初期位置に加算し、中心でなく球体表面から発生させる。「Mesh RendererのPivot Offsetに似た発想だが、User Parameter化することでレベル側から調整できる点が異なる」と比較して説明
- Add Velocityにも同様の Multiply Vector by Float（Mesh Rotation X軸 × 速度100）を使い、各パーティクルがそれぞれの向いた方向に飛んでいく動きを作る。Dragモジュールを追加して減速させ、固定位置に留まるより自然に見えると評価
- Dynamic Material Parameter：Sphere Fadeは徐々に減少、Hex Boostは値を10〜100倍に強く底上げ（通常時より大幅に強い発光にする）、Brake Powerも設定（詳細値の言及は薄い）

### 6. キャラクターへのアタッチと実演 [19:16]-[21:09]
- 「最もシンプルな方法」として、Impact SystemとShield Systemを直接アタッチし、さらにキャラクターをシールドに位置合わせでアタッチする方式を採用（他の方法もあり得るが本動画では扱わない、と言及）
- Level Blueprintでキャストアニメーション終了（0.7〜0.8秒）を待ってから両Niagara SystemをActivateする実装。Auto Activateは両方無効化し、明示的に発火制御
- 実演では18秒間隔でループ再生、その中で被弾エフェクトは3秒おきに発火、シールド本体の持続時間は15秒に設定。キャラクターサイズに合わせてシールドスケールを0.7に調整

## 新規性のある技術情報（既存ドクトリンとの比較）

- **Emitter Loop Countをintソースとした経過ループ数の値計算**：doctrine v2.4には「Execution State=寿命制御、Inheritanceで差分量産」という一般論はあるが、「複数回ループするEmitter内でパーティクルの見た目（回転など）を前回ループの終了状態から連続させるために、Loop Countを掛け算のソースとして使う」という具体的パターンは既存ノート群になく新規。ループ跨ぎの状態継承という、Niagara特有の実装上の落とし穴と解法
- **Loop Delay ≠ Loop Duration の罠**：両方セットしないとパーティクルが発火しないという実演上のバグ修正シーンは、地味だが再現性のある注意点として新規
- **スポーンタイミングを他Emitterの継続時間から逆算する設計**（Loop Delay 0.5s + Loop Count(=秒数として流用)）：Emitter間の依存関係をUser Parameter経由で数式接続する考え方は、既存ノートの「User Parameterでの外部化」パターンをさらに一歩進め、Emitter同士の時間的連携に応用した例
- **Return Exec Index × 定数 での放射状N方向配置**：Spawn Count=Nと組み合わせてN方向に等間隔回転させる最小実装。既存ドクトリンの「1粒バースト+カーブ駆動の器」パターンとは別軸（多方向対称配置）の定型として追記価値あり
- シールド全体を「出現／常駐ループ／破壊／被弾」の4状態に分けてEmitter/Systemを差分複製する設計思想自体は、既存ノートの「System階層=監督」パターンの実例だが、**状態遷移が時間軸で連続する（出現→常駐→破壊）UIケースへの適用例**として新規

## SCRAP BLITZ UEへの応用メモ

- **被弾時のシールド演出**：本動画のImpact System（4方向 Exec Index配置＋Add Velocity＋Drag＋テンションカーブ）は、防御技や被弾無効化演出にそのまま転用できる構造。SCRAP BLITZ側で「防御中に攻撃を受けた」イベントで別Niagara Systemを単発Activateする設計は、既存のAOEテレグラフ文法とも競合しない（テレグラフ＝常時警告演出、Impact＝単発反応演出で役割が異なる）
- **防御技の視覚化（出現→持続→解除）**：METEOやボスの防御・無敵状態表現に「出現エフェクト（短時間・強い発光）→常駐ループ（控えめ・安定発光）→解除エフェクト（破壊/シャッター）」という3段階構成をそのまま流用可能。特に常駐ループでのScale Color固定（開始=終了値でフェードさせない）は、無敵時間中ずっと視認できるシールド表現に直結する
- **Loop Count連動の回転継承テクニック**は、SCRAP BLITZのオーラ/バリア系エフェクトが長時間表示される場合（ボスのシールドフェーズ等）に、パーティクルの回転がループ毎にリセットされて不自然に見える問題を事前に回避する設計として有用
- **Dynamic Material Parameterの4分割設計**（歪み/内部フェード/エッジ発光/破壊度）は、既存の「値の設定と評価モジュールは分離」ドクトリンと整合的。SCRAP BLITZでシールド系マテリアルを新規に作る際は、最低限この4系統を公開しておけばNiagara側だけで出現→常駐→破壊の演出を作り切れる、という設計テンプレートとして参考になる
- 注意点：本動画はメッシュベース（既製hexメッシュ）の実装であり、`omkwqdWMB_U`（プレーン+プロシージャルマテリアルでドット/ノイズ模様のバリア）とは前提が異なる。SCRAP BLITZでどちらの方式を取るかは、シールド形状の自由度（メッシュ差し替え可否）とアート方向性次第で選定する必要がある
