## 概要

前作で作った「エッジ回転のみのシンプルなポータル」に、内部（インテリア）の渦・歪み・疑似視差を追加してビジュアルを強化する続編。マテリアルのみで完結させ、メッシュ UV に依存しない手法を明示的に選んでいる点が主題。

## エッジ形状（前作の再確認・簡略）

- **Vector To Radial Value**（UV を中心からの極座標的な値に変換）+ **Radial Gradient**（可視範囲・フェードの制御）の組み合わせで回転エッジを作る、とだけ振り返られる。ノード接続の詳細な図解は本動画になし（前作依存）

## インテリアエフェクトの構築（マテリアル複製から）

1. エッジ用マテリアルを複製・リネームし、そこにインテリア用ノードを追加していく方式
2. エッジ形状を定義するノード群（および Blend ノード）をコピーし、**Radial Gradient を乗算**
3. `1 - x` した結果に **Float で強度制御用の乗算**を追加
   - この時点で中心付近の値が0に近く、エッジ付近が1に近くなる → 「エッジは明るく、中心に向かって暗くフェードする」インテリア表現の狙いに合致
4. 必要に応じて **Particle Color を乗算**
5. **Dynamic Material Parameter** でインテリアの強度を外部制御可能にする
6. インテリア色はエッジより弱くすべきという判断から、さらに **×0.2** を乗算
7. Emissive Color に加算合成（Add）
8. マテリアルエディタのプレビューでは色が目立たないため、**Niagara 上で確認**（Niagara 側の色強度の方が強く出るため）とコメントあり

## 内向き渦（vortex velocity）への反転

- 初期実装ではエッジ効果が外側に広がる挙動になってしまい、「周囲から内側に向かって吸い込まれる」ような渦（vortex velocity 的な動き）に反転させる調整を実施
- 手順:
  1. Panner の **Y軸成分**を取り出す
  2. それを **Radial 変換**し、内向き/外向きの移動方向を制御する値として使う。**0.5 に設定すると内向きの動きになる**、と明言（この値の意味付けの詳細な数式ロジックは字幕からは不明瞭※推定）
  3. 同様の変換をもう一方にも適用
  4. Velocity 値を上げて動きを速く（**1 と 0.5** に設定、と字幕にあり※推定：どちらがどのパラメータかは文脈から完全確定できず）
  5. 色を強めてプレビューしやすくする調整も併用

## メッシュ UV 非依存の歪み（distortion）手法 — 本ノートの核心

- 通常この種の渦状歪みは **Disc メッシュの UV を歪ませて**実現する（Plane の X/Y Velocity で捻れた見た目を作る、と説明）。これはメッシュ側に依存する前提の手法として一度言及される
- 本動画で紹介される**メッシュ非依存・マテリアルのみで完結する代替手法**:
  1. 新しい **Radial Gradient** を追加
  2. そこに **Time ノード**を加算
  3. その結果を **Panner の Time 入力**に接続
  4. これだけで、メッシュ UV を捻ったのと同様の渦状の歪み効果が得られる、と実演される（「ピクセルごとに開始タイミングが異なることで歪みが生まれる」という説明）
  5. **Radius（歪みの半径）と Density（歪みの強さ）を Float パラメータ化**。Radius は 0.5 が例示値。Density は「1 では控えめ、2〜3ではかなり強い歪みになる」と幅を持って説明される
- この Panner の Time 入力に Radial Gradient + Time を流し込むという構成は、既存 doctrine の「UV 制御は1関数に集約（Panner→Add→CustomRotator）」パターンとは別軸の**Panner の Time 入力そのものを歪ませて疑似渦を作る手法**であり、既存ノートに未収録

## Bump Offset による疑似視差（parallax）

- **Vector To Radial Value** の結果を Bump Offset の座標入力に接続
- Bump Offset の **Height** が視差の深度を制御（本動画では `-5` を設定、と字幕にあり※推定）
- 完全に平坦な Plane 上で視差を全面にかけると不自然になるため、**Radial Gradient で視差量そのものを中心から周辺にかけてフェードアウト**させ、「中心が最も強く、エッジではほぼゼロ」という分布にする。これは前段のインテリア吸い込み表現（内向き〜後方への吸引）とビジュアル的に整合させる意図と説明される
- Radial Gradient の Radius を `1` に設定
- ノイズテクスチャでは効果が分かりにくいため、**組み込みテクスチャ2種（人型シルエットのテクスチャ含む）で差し替えてテスト**し、視差効果が中心で強く・エッジでほぼ無い、という分布を目視確認するデモが挿入される

## Niagara 側のセットアップ（簡易）

- Mesh Renderer、デフォルトの Plane メッシュを使用
- 色を強めてポータルの発光を強調
- **Scale（メッシュサイズ）を 0 → 1 → 0** とカーブ駆動
- 常時カメラの方を向くビルボード的な基本回転処理あり（詳細な実装手法の説明はなし）

## 新規性のある技術情報（既存ドクトリンとの比較）

`fx_technique_doctrine.md` には Radial Gradient Exponential を使った電撃/グロー系のパターン（グロー勾配節）はあるが、以下は未収録で新規:

- **Panner の Time 入力に「Radial Gradient + Time」を接続することで、メッシュ UV 変形なしに渦状の歪みを作る**手法（メッシュ非依存の distortion 代替パターンとして doctrine の「UV 制御は1関数に集約」節に追記候補）

## SCRAP BLITZ UEへの応用メモ

- ステージ演出（ワープ/転送/出現ギミック）への転用は**構造的に相性が良い**: 本テクニックは「Radial Gradient ベースの円形マテリアル + Panner Time 入力歪み + Bump Offset 視差」という**マテリアルのみで完結する軽量構成**であり、Niagara 側は Plane メッシュ1枚 + スケールカーブという最小構成。既存 doctrine の「1粒バースト+カーブ駆動の器」原則（Light/Decal/柱メッシュ）と同じ軽量思想に合致する
- **ワープ/転送ギミック**（例: ステージ切替ポータル、リスポーン地点、ボス戦フェーズ切替の演出）に直結: 内向き渦（吸い込み）表現は「プレイヤーが吸い込まれて転送される」演出との親和性が高い。エッジの回転+インテリアの渦+疑似視差の3層構成は、2.5D固定カメラでも正面から見える円形/リング状ギミックとして機能しやすい
- **出現ギミック**（敵の召喚、アイテムの出現）にも Scale 0→1→0 のカーブ駆動パターンをそのまま流用可能。ボス召喚演出や隠しエリア出現時の「渦から実体化する」表現に応用できる
- 疑似視差（Bump Offset + Radial Gradient フェード）は、固定 2.5D カメラでは奥行きの実在感を安く演出できる手法として、OC ジェムや浮遊オーブ系の既存 Niagara 資産（`iDrsEp3AGWA_magic-orbs.md`）にも転用余地がある可能性
