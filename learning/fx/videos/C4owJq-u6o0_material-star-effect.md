## 概要

テクスチャを一切使わず、Material Editor のノード演算だけで「星形」マスクを作るチュートリアル。2 通りの作り方が示される：(1) Sphere Mask を整数格子でタイリングして 4 隅に複製する方法、(2) TexCoord の絶対値の積を Radial Gradient 駆動の可変指数で累乗して星の尖りを作る方法。仕上げに Time ベースの明滅（flicker）エミッシブを加える。

## 技術詳細

### 手法1: Sphere Mask + Ceil/Floor による整数格子タイリング（本ノートの核心）

1. Sphere Mask ノードを作成。入力 A = UV（TexCoord）、入力 B = 円の中心
   - 入力が 2D/3D どちらのベクトルかで距離空間の次元が決まる、と説明される
   - 中心を `(0,0)` にすると、プレビューの可視範囲が `0〜1` のため実質「四分円」しか見えない
2. 素朴には中心座標を 4 隅（`(0,0) (1,0) (0,1) (1,1)`）にずらしたノードを 4 つ複製すれば四隅に丸が並ぶが、「ノードを 4 回複製するのは面倒」と課題提起
3. **タイリングによる 1 ノード解決**:
   - TexCoord に `0.5` を Add → 値域が `0.5〜1.5` にシフト
   - その結果に **Ceil**（切り上げ）を適用 → 4 隅の領域がそれぞれ整数値 `(1,1) (2,1) (1,2) (2,2)` に潰れる（各領域内で値が変化しない「階段状」になる）
   - Ceil の結果から再度 `0.5` を Subtract → 各領域が `(0.5,0.5) (1.5,0.5) (0.5,1.5) (1.5,1.5)` という**その領域が属するタイルの中心座標**に変換される
   - この結果を Sphere Mask の入力 B（中心）に接続することで、**UV 全体を 4 タイルに分割し、各タイルの中心に自動的にコピーされた円マスク**が 1 つの Sphere Mask ノードだけで得られる
   - Floor（切り下げ）でも同様の効果が作れると言及（Ceil/Floor はどちらを使うかでタイルの基準コーナーが変わるだけ、と推測される。※推定：字幕からは Ceil/Floor の使い分け基準の詳細な数式的説明はなし）
4. `1 - SphereMask`（One Minus）を取ることで「中心が白（visible=1）、外周が黒（invisible=0）」の星形マスクを得て、そのまま Opacity と Emissive Color に接続

### 手法2: Abs(TexCoord) の積 × Radial Gradient 駆動の可変指数 Power（もう一つの星形生成法）

1. TexCoord から `0.5` を Subtract → 値域 `-0.5〜0.5`
2. Component Mask で R チャンネル・G チャンネルをそれぞれ分離し、各々に **Absolute** を適用（`-0.5〜0.5` → `0〜0.5` に折り返し）
3. Abs(R) と Abs(G) を **Multiply** → 十字/ダイヤモンド状の形状になり、「星に近い形」と説明される
4. **Power ノードで累乗し先鋭化**: 指数（Exponent）側に **Radial Gradient（Exponential）** ノードの出力を接続し、位置に応じて指数が変化する累乗を行う（※推定：字幕の該当箇所は "power the minus output" 等の表現が不明瞭で、正確なノード接続順序（符号反転の位置）は完全には特定できず、実機での再現確認が必要）
   - Radial Gradient の Exponent（強度）定数を `200` に設定
   - Radial Gradient の Radius を `0.8` に調整すると星形のバランスが良くなる、とデモされる
5. 出力を Opacity に接続。Emissive Color には 3D Vector 定数（例 `(100, 1, 1)`）を乗算し、HDR 値の高い R チャンネルで赤い発光（グロー/ブルーム対応）を作る

### 明滅（flicker）エミッシブの付加

- Time ノード → Sine（もしくは同等の周期関数、字幕上「same function」とのみ言及）で `-1〜1` のループ値を作る
- Constant Bias Scale 的な処理（`+1` して `×0.5`）で値域を `0〜1` に正規化
- ただし「値が 0 になると完全に非表示になってしまう」ため、下限を持ち上げるための定数（字幕上「pairs value」＝ Power/Bias 系ノードと推測、※推定）を `2` に設定
- この明滅値を Multiply で Emissive Color の 3D Vector 定数側に掛け合わせ、星全体が周期的に明るさを変える演出にする

### 基礎概念の補足（本シリーズの初心者向け解説パート）

- Blend Mode は Translucent / Additive を多用、Shading Model は Unlit を多用すると説明
- Two Sided（両面表示）の on/off でメッシュの裏面が見えるかどうかが変わる、という基礎解説あり
- Text（Constant）ノードの作り方（`U` キー + 左クリック）、Ctrl+ドラッグでの UE 公式ドキュメント参照方法など、エディタ操作の基礎 Tips も含まれる（本ノートでは割愛、技術内容に限定）

## 新規性のある技術情報（既存ドクトリンとの比較）

`fx_technique_doctrine.md` にはグロー勾配節で Radial Gradient Exponential の言及があるが、以下は未収録で新規：

- **`Ceil(UV + 0.5) - 0.5` による UV タイル中心座標抽出**: 1 つの Sphere Mask ノードを複製せずに UV 空間を格子状にタイリングし、各タイルの中心に自動的に配置されたマスクを得る手法。`basic-shape.md` の直交座標ベース SDF 的アプローチとも異なる、**整数格子演算による位置複製パターン**。反復模様（グリッド状のキラキラ・タイル状ディテール）を作る際の一般化可能な技法
- **Radial Gradient の出力を Power ノードの指数（Exponent）側に接続する**という、可変指数累乗によるシルエット先鋭化パターン。既存ドクトリンの Power は「ノイズ→Power→Opacity(Mask)」という Erosion 定型でのみ言及されており、**位置依存の可変指数**という使い方は新規
- Abs(R)×Abs(G) のダイヤモンド形状を土台に、可変指数 Power で星型に変形するという、**幾何形状の合成 → 累乗による輪郭変形**の 2 段階構成パターン

## SCRAP BLITZ UEへの応用メモ

- **星形パーツ（アイテムキラキラ演出）への直接転用が可能**: 本動画の手法はテクスチャ 0 枚・ノード演算のみで星形マスクを作れるため、既存の OC ジェムや Pickup 系エフェクトの「キラッ」とした装飾パーツをテクスチャアセットなしで量産できる。特に手法1（Ceil/Floor タイリング）は、複数の星を等間隔グリッドで散りばめる背景装飾（例: レベルアップ演出の背景に小さな星を多数配置）に応用しやすい
- **コンボ表示装飾への応用**: `common01.md` のコンボ演出・BURST 化 HUD 周りで「達成時に星型のキラキラが弾ける」ような装飾を追加する場合、Emissive Color に HDR 高値（R=100 等）を使うグロー表現と、Time 駆動の明滅パターンがそのまま流用できる。現状 `SBComboHUD` は Canvas 描画中心だが、将来 Niagara/UMG マテリアルベースの装飾に切り替える際のベース技術として採用余地あり
- **可変指数 Power（Radial Gradient を Exponent に接続）は星形以外にも応用範囲が広い**: 位置に応じてエッジのシャープさが変わる形状全般（例: SP ゲージ満タン時のトゲトゲ演出、警告テレグラフのギザギザ縁取り）に転用できる可能性がある。既存 doctrine の AOE テレグラフ定型（固定赤枠/円 + 橙塗り）に「エッジをシャープなギザギザにする」バリエーションを加える際の技術候補
- 手法2 の Abs×Abs→Power 構成は `basic-shape.md` の三角形/矩形パターンと同系統の「ノード演算のみで幾何形状を作る」軽量化路線に合致し、HUD 装飾パーツのテクスチャレス化という方針を両ノートで共有できる
