## 概要

キャラクターが飛行しながらダッシュする際に付随する「残像/風切り」系エフェクトを、Static Mesh（カプセル状の汎用形状）+ Mesh Renderer + 2種のマテリアルで構築する短編。テクスチャ2枚（水の擬似コースティック風テクスチャ、波形マスクテクスチャ）と、標準UVレイアウトを持つ既製メッシュを使い回す設計が主題。「他のオブジェクトのダッシュ演出にも転用できる」と冒頭で明言されており、汎用エフェクトとして意図されている。

## 技術詳細

### 使用アセット
- Static Mesh: カプセル状の形状。**デフォルトのボックス/シリンダー投影UV**（メッシュ制作時に特殊なUV展開をしていない、既製の標準レイアウト）。動画内で「VFX用メッシュの多くはこの標準UVを使う。Pannerでのテクスチャ制御がしやすいため」と明言
- テクスチャ2枚: 水のコースティック風ノーマルテクスチャ（エンジン標準の water normal を流用）、波形マスクテクスチャ（Patreon配布、詳細不明）
- キャラは Mixamo の飛行アニメーションをプレースホルダに使用

### マテリアル1（メイン形状・仮称 Dash Main）
1. **ディストートマスクをRとGチャンネル別に用意**: 同じテクスチャのUVタイリング(2, 0.5)、Panner速度を(-1, -2)の2系統で分離パンし、それぞれ0.5倍して歪み強度を弱める
2. 波形マスクテクスチャ（UVタイリング2,1）に左右方向のランダムUオフセットを加えてから上記ディストートを適用
3. **ディストート範囲にグラデーションマスクを追加**: メッシュUVがタイル状に全体に貼られているため、ディストートで歪ませると別の領域のテクスチャが意図しない位置（下端）にはみ出す。これを防ぐため下端をマスクで除外
4. 得られたシェイプを Power 0.5 → ×2 → Lerp でハイライト（反射的な明部）を作る
5. 同シェイプを Power 1.5 → ×100 して元シェイプに加算し、明るい前景と暗い背景のコントラストを作る
6. 別途、同シェイプを ×0.25 して別のグラデーションマスク（V方向タイリング0.5＝サイン波半周期）と合成し最終形状を得る
7. **Opacity**: 最終形状 × Fresnel × Particle Color の Alpha チャンネル（Reflection 成分も同じ配線に合流）
8. **Emissive**: 同テクスチャを再度使用（UVタイリング1,0.5、Pannerスピード0.5）してディストートし、完成シェイプに乗算、値を減衰後クランプ(0-1)、**Derive HDR from LDR** ノードで HDR 化 → Particle Color を乗算

### マテリアル2（グロー・エッジ用、仮称 Dash Glow）
- 同じ water normal テクスチャで別パラメータのディストート（UVタイリング1×0.75、速度0.1/0.05。この速度値を上げるとダッシュが速く見えると明言）
- コースティック風テクスチャを2系統（速度違い: 0.2/-1 と 0.2/-0.25、UVタイリング違い）Lerp でブレンド、V方向のグラデーションマスクをAlpha入力に使用
- 下端マスク（マテリアル1と同じ理由）→ ×5 で強調 → クランプ(0-1) → Fresnel・Particle Color Alpha を乗算 → **Depth Fade** に接続してOpacityとする（マテリアル1にはない Depth Fade がここで追加されている点が差分）
- Emissive はPowerで暗部を強調（露出指数を大きめにして上部のみ残す）、クランプ後 Derive HDR from LDR → Particle Color・Fresnel を乗算
- 追加でWorld Position Offsetにも軽く言及: Vertex Normal (World Space) × ノイズテクスチャ × グラデーションマスクで、メッシュ前面（テクスチャが乗る側）のみ動的な形状変化を加える簡易実装

### Niagara セットアップ
- **メインエミッタ（Dash Main材質）**: Mesh Renderer + 上記マテリアル。Life Cycle=Infinite、Spawn Rate=10、Particle寿命ランダム0.2〜0.3秒
- Color は User Parameter 経由（デフォルト赤）で外部制御可能に
- **Mesh Size**: メッシュがX軸を向いている前提で、X軸のみランダム5〜10、Y/Z軸は固定5（**進行軸のみ非対称にスケール**する設計）
- **Initial Mesh Orientation**: X軸回りのランダム初期回転を付与
- **Update Mesh Orientation**（Updateステージ）: X軸回転速度をランダム0.5〜1で継続付与し、メッシュが飛びながら回転し続ける挙動を作る
- **Scale Color**: Float from Curve（デフォルトカーブテンプレート）、Alphaスケール500→その後カーブスケールを1に調整
- **Scale Mesh Size**: Float from Curveで0→1のカーブを使いスポーン直後にサイズがゼロから立ち上がる
- キャラにアタッチする際は **Local Space** 設定が必須（ワールド空間のままだとキャラ追従しない）。サイズは実機で0.5倍程度に調整
- **2つ目のエミッタ（Dash Glow材質）**: 上記エミッタを複製しマテリアルのみDash Glowに差し替え。Spawn Count=20、寿命1（〜値は動画中で聞き取り不確定、後続部分が字幕欠落）
- Color/Mesh Size/Initial Orientation はデフォルト値を維持
- **Scale Mesh Size を Vector from Curve に変更**（メインエミッタのFloat from Curveと異なりベクトル化）: Y/Z軸は1で固定、X軸のみ0.5〜1のカーブ
- **Scale Color**: Alphaスケールを0.1に下げ黒つぶれ域を減らす一方、色そのものは5000倍に強化
- Random Mesh Orientation を -1〜1（負方向も含む）に拡張し回転にランダム性を加える

## 新規性のある技術情報（既存ドクトリンとの比較）

`fx_technique_doctrine.md` の「ストレッチ」節は Size Non-uniform + Velocity Alignment が定型だが、本動画はこれとは異なる系統:

- **Mesh Renderer + Initial/Update Mesh Orientation によるメッシュ自体の継続回転**を「移動中の残像」表現に使う手法。Velocity Alignment（進行方向にストレッチ）ではなく、進行軸方向のみ非対称スケール（X軸5〜10、Y/Z固定5）した回転メッシュを一定間隔でスポーンさせる構成で、ドクトリンのストレッチ節・トレイル/光の筋節のどちらとも異なる第3のダッシュ表現パターン
- **Scale Mesh Size を Float から Vector に切り替えて特定軸のみカーブ駆動する**という、同じ「Scale Mesh Size」モジュールの中での使い分け実例（メインは全軸一様Float、グローは進行軸のみVectorで非対称）
- マテリアル面では、同一テクスチャ資産から**メインシェイプ用とグロー用で異なるディストート配線・異なるOpacity合成経路（Depth Fadeの有無）を持つ姉妹マテリアルを2枚作る**という設計判断。ドクトリンの「グロー勾配」節・「Erosion定型」節と要素は重なるが、Depth Fadeをグロー側だけに使い分ける具体判断は未収録
- 2エミッタ構成（メインとグロー）を**同一の元エミッタから複製し、Scale Mesh Size / Scale Color / Random Mesh Orientation の3モジュールだけ差し替える**という最小差分でのバリアント量産パターンは、ドクトリンの「System 階層=監督」パターンとは別軸（エミッタ複製ベースの量産）で新規

## SCRAP BLITZ UEへの応用メモ

- METEO の高速移動技（ダッシュ攻撃・回避ステップ）の残像/風切り演出に直結する候補。既存の「トレイル/光の筋」系（Ribbon・Sprite Pivot）とは異なり、**メッシュを回転させながら断続的にスポーンする**手法のため、2.5D固定カメラでもメッシュの厚み・立体感が出しやすく、平面的なRibbonトレイルでは表現しにくい「空気を切る質感」の付与に向く
- SP技のダッシュ突進演出やボスの高速チャージ攻撃の予兆〜本体移動区間にも同様の構成（進行軸のみ非対称スケール＋回転する短命メッシュの連続スポーン）を転用できる。ただしメッシュ資産（カプセル状・標準UV）を新規に用意する必要があり、既存のNiagara資産（トレイル系）ほど低コストではない点に留意
- Local Space 必須という運用上の注意は、既存の Skeletal Mesh Location によるキャラ付随FX全般（オーラ等）と共通する落とし穴であり、新規実装時にチェックリスト化する価値がある
