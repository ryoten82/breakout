# ライティング・ドクトリン（蒸留版 v1）

Epic 公式 doc 2 本 + SQEX 講演スライド 1 本（いずれもペア照合済）からの横断抽出（2026-07-04 初版）。**日常はこのファイルだけ読む**（上限 3KB）。詳細は `videos/`（Sonnet 委譲）。

## 基礎（Epic 公式）

1. Light Type 5 種 / Mobility 3 状態。**Stationary は重複 4 灯まで**（超過は Movable 落ち）
2. Lumen = 動的 GI・反射。Nanite / World Partition / Virtual Shadow Maps と統合前提の設計
3. bg ドクトリン§影の設計（CSM+DFS+FarCascade・重いライト 5 点検）と対で使う

## 調整ワークフロー（SQEX 講演・「光の感性」実務編）

4. **Exposure ロックが先** — Min EV100 = Max EV100 で固定・Auto 無効。明暗はライティングの根幹なので自動調整に奪わせない（bg§1 と同旨・手順が具体化）
5. **色はライトの色で作る** — PPV の Temperature に頼らない。WhiteBalance はデフォルト維持
6. **角度決定は極端値で分離** — Detail Lighting（Alt+5）+ Intensity 一時 100・Skylight 0 で「影の形」だけ決める → 決まってから通常光量へ戻す。**光量とアングルを同時に触ると判断がぶれる**
7. **光の質 = SourceRadius** — 5=硬い光 / 80=柔らかい光（影のボケ・質感描写を支配）
8. **ライトの Pivot は対象に置く**（PivotOffset 100〜300・キャラの胸あたり）— 回転調整が楽になる
9. **同設定コピー禁止** — 複数灯は色・サイズを毎回変える（円環グラデ配置で「方向性のある光の流れ」）
10. **引き算も使う** — 黒い板で光を遮る「黒で締める」。足すだけがライティングではない
11. **トーンマッパで全バランスが変わる** — ライト調整と Color Grading / ToneCurve は往復で詰める

## 場面別の判断

- **Emissive が豊富なシーン（SF 都市・機械文明）は直射光を弱められる** — 発光アセットで画が持つ。Stage 3 のネオン柱・発光球体と相性の良い考え方
- Skylight tint は「空の色が影に映る」物理的直感で薄く色付け（極端にしない）
- 練習・検証は**夜間・室内・無機空間**で（昼外は太陽が支配的で発見が少ない）
- **Lumen Hit Lighting（5.5+）**: Ray Lighting Mode = Hit Lighting でキャラ（Skeletal Mesh）が周囲 GI に寄与できる。⚠設定パスの正確な表記はスライド上曖昧・実装時に現物確認
