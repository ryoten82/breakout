## 全体ワークフロー（工程順）

小規模な「点A→点Bを歩くだけ」の短い通路マップを、レベル構築 → ライティング → フォグ/ポストプロセス → パーティクルの順で仕上げる構成。

1. **プロジェクト初期化** [00:19–00:53] — File → New Level → Empty Level → Create。無料アセット「Polar」「Spaceship Interior」の存在を確認（FAB/Quixelストアからダウンロード可能、説明欄にリンク）
2. **アセットブラウズの下準備** [00:53–01:33] — コンテンツブラウザで Filters → Static Mesh に絞り込み → 対象フォルダ（Polar）に絞る → ビューポート表示モードを **Unlit** に切替（ライティング無視で形状・配置を見やすくするため）
3. **床の配置** [01:37–03:00] — 穴あき・変な角度の床メッシュを避けて、隙間のない床piece を選定 → Grid snap / Rotation snap / Scale snap を全て有効化 → Alt+ドラッグで複製しながら敷き詰め、通路の主レイアウトを作る。移動系ショートカット：Q=選択、W=移動、E=回転、R=スケール
4. **プレイヤー動線とスケール決め** [03:49–04:51] — 一部の床を拡大して「開けたエリア」を作る → PlayerStart を配置し、開始地点から終着エリアまでの動線を決定
5. **壁の設置** [04:51–07:36] — 各コーナーに壁ピースを配置 → コピー＆90度回転で隣接面を作る → スケール不一致の壁は snap を一時解除して手動調整 → 隣接する壁同士が完全一致すると z-fighting が出るため、片方をわずかに拡大してズラして回避
6. **天井の生成** [07:36–08:27] — アウトライナーで "floor" 名の付くメッシュを検索・複数選択 → コピー＆貼り付けして天井として転用 → スケールを反転（内向き）
7. **柱（ピラー）配置** [08:27–09:34] — Polar 内の pillar メッシュをコーナーに配置。綺麗に収まらない角には Spaceship Interior 側の「piping（配管）」メッシュを代用
8. **ポイントライト設置** [10:38–11:40付近、字幕欠落あり] — 天井の照明メッシュの下に Point Light を追加。Attenuation Range ≒600〜800（※推定）、Intensity は主要箇所6・補助箇所2、色温度をわずかに黄色寄りに調整
9. **配管でグラフィックバグ隠し** [11:53–12:13] — 露出した継ぎ目・アーティファクトが目立つ箇所に配管メッシュを重ねて視覚的に隠す
10. **Exponential Height Fog 追加** [12:30–13:14] — Fog Scattering の色を赤みがかった色に設定 → Density を試行錯誤
11. **Post Process Volume 設定** [13:14–13:53] — Scale 500×500×500 → Bloom ON → Exposure Bias（Manual）を1刻みで試行：-5（明るすぎ）→ -1（まずまず）→ 0.5, 3 → ホラー系なので暗め方向の2.5〜4を採用
12. **ライトのMovable化 & フォグ再調整** [13:53–14:20] — 全ライトを Movable に変更 → Height Fog に戻ってより「もやった」見た目に再調整
13. **パーティクル（Cascade）追加** [14:20–15:53] — 旧版 Particle System（Cascade）でアンビエントダスト（サイズ・密度を場所ごとに変化）→ ケーブル付近にスパークパーティクル（控えめ）→ 複数コーナーにスチームパーティクル
14. **仕上げ・確認** [15:57–17:16] — 最終ウォークスルー → 残っていた z-fighting をメッシュの微調整で解消 → サウンド未実装であることに言及して締め

## クオリティを上げる教訓（SCRAP BLITZ に効く順）

### 1. 「隠す」ための小道具（プロップ）の使い方 [09:02–09:34, 11:53–12:13]
綺麗にメッシュが収まらない箇所（コーナーの柱、壁の継ぎ目のz-fighting）を、**配管（piping）のような装飾メッシュで覆い隠す**という運用上の判断基準。厳密なジオメトリ整合を追い込むより、視線の通る位置に小道具を足して誤魔化す方が実務的に速い。SCRAP BLITZ の Stage 3 SF backdrop でも、ネオン柱の設置面や発光球体のワイヤ外殻の継ぎ目処理に応用できる考え方。

### 2. ライティングは「主要light=強め・補助light=弱め」の非対称配置 [10:52–11:40]
全てのライトを同じ intensity にせず、意味のある光源（照明器具の真下など）は intensity 6、単に暗がりを潰すためだけの補助光は intensity 2、という役割によって強度を変える判断。Stage 3 の巨大発光球体を主光源格として扱い、周辺のネオン柱を補助光的に弱めに設定する参考になる。

### 3. Exposure（Manual）は「値が大きいほど暗い」を体感的に試行する [13:24–13:53]
-5（明るすぎ）→ -1（許容範囲）→ 0.5, 3 → 最終的にホラー演出のため2.5〜4を選択。ジャンルのトーン（今回はホラー＝暗め）に応じてExposureの方向を決めるという判断基準は、SCRAP BLITZ のポストプロセスでも「SF/シリアス寄り」か「ポップ」かでExposure方向を変える指針になる。

### 4. フォグは色付け＋density の2段階チューニング [12:30–13:14, 14:03–14:20]
Fog Scattering Color を先に決め、その後 Density を過多から徐々に落として着地させる。Post Process の Bloom / Exposure を決めた**後**にもう一度 Height Fog に戻って微調整している点は、前掲ノート（ee-IOlWUZTo）の「ムード先行→物量」に対して「ライト→フォグ→ポストプロセス→フォグ再調整」という行ったり来たりの反復調整が実務では普通、という補足になる。

### 5. パーティクルは全面ではなく要所配置、種類ごとに密度を変える [14:44–15:53]
アンビエントダストは「たまに大きく」「全面ではなく要所に十分な量」、スパークは「控えめ」、スチームは「複数コーナーに分散」と、パーティクル種類ごとに配置密度のポリシーが異なる。SCRAP BLITZ 背景でネオン柱周辺にスパーク/スチーム系の環境パーティクルを足す際の匙加減の参考になる。

### 6. スナップ機能は「基本ON、辻褄が合わない箇所だけ一時OFF」 [01:52–02:29, 06:01]
Grid/Rotation/Scale の snap は基本すべて有効化した状態で作業し、サイズの合わない壁ピースなど例外的な箇所でのみ scale snap を無効化して手動調整する。無料アセット寄せ集めで完全にモジュール寸法が揃わない場合の実務対応。
