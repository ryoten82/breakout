## クオリティを上げる教訓（SCRAP BLITZ に効く順）

### 1. 大きい構造から置いて「画面のフレーミング」を先に決める [03:49–04:30]
講師は set dressing の最初にシッピングコンテナや柱など大きい構造材から置く。理由は明言されている:
- シッピングコンテナ = **視線を画面内に留める barrier**、同時にコンテナの直線が**建物へ視線を誘導する leading line** になる [03:56–04:08]
- 柱の追加は**二階を支える**だけでなく、**面白い陰影ができる場所** と**ディテール・set dressing を置ける表面積の確保**を兼ねる [04:10–04:19]
- 側面・背面をブロックするのは**シーンをシンプルに保ち、建設エリアに焦点を絞るため** [04:24–04:30]
→ 産業ヤードの「まず何もない空間に大枠のコンテナ/構造物を置いて画面を閉じる」考え方は、廃工場・廃滑走路ヤードのブロックアウトにそのまま転用可能

### 2. アンカーポイントからストーリーを広げる（小物配置の思想）[04:49–06:44]
- ブロック（コンクリートブロック等）は**面白いディテールと影を作り**、**ストーリー性**と**有機的な崩れ（breakup）** を加えるために置く [04:49–05:00]
- **小さな回転を加えて、他の leading line と完全に平行にならないようにする** — 完璧な整列を崩すことがリアリズムを売る鍵 [05:00–05:12]
- セメント袋のような有機的アセットは**互いにもたれ掛けさせる（lean）配置**が有効。「作業員が置いたであろう」姿を想像することでリアリズムと生活感が出る [05:32–05:46]
- **アンカーポイントからストーリーを広げる**: セメント袋を置いたら、それに呼応してセメントミキサーを足す、というように「関連する物」を後から足していく手法 [05:50–06:01]
- 一方の側にコンテナで leading line を作ったら、**反対側の建物の直線も別の要素で崩す**（シッピングコンテナと同じ役割を別アセットで反復） [06:04–06:09]
- 廃材（waste materials）を周辺に足してストーリーを補強 [06:14–06:20]
- 建物が単調に見えてきたら「未完成の部分（partially constructed areas）」を足して**工事中である**ことを示す — work in progress の説得力を上げる常套手段 [06:31–06:44]
→ これは産業系小物配置の核心教訓：**「アンカー→関連物」の連鎖でストーリーを積む**、**小回転で直線を崩す**、**寄り掛からせる配置**の 3 点は、本プロジェクトの廃工場ヤードの資材・重機配置にそのまま適用できる

### 3. 足場は「視覚的興味」と「構図のブロッキング」の両方に使う [07:02–09:01]
- 足場は垂直方向の視覚的興味を足し、ディテールの密度を上げつつ**構図を分割する**役割 [07:02–07:16]
- 足場が背景の空（何も手を加えていない部分）を隠してくれるので、**視線をアセット自体に留める**ことに使える [08:29–08:39]
- 足場をより高くしてフォーカルポイントの一部に寄せることも試行 [08:44–08:58]
- 下段の脚を外して**二段重ね（double stacked）** にするなど、既存アセンブリの改造で高さを稼ぐ [09:01–09:13]

### 4. Packed Level Actor による再利用プレハブ化とバリエーション生成 [07:28–08:06]
- Packed Level Actor は**再利用可能なプレハブ**を作るために使う。後で元プレハブを更新すると**全インスタンスに伝播する**利点がある [07:28–07:41]
- 繰り返し感を減らす早くて効果的な方法：**既存の Packed Level Instance を分解（break apart）し、変更を加えて別バリエーションとして再パッケージする**。ゼロから作るより効率的 [07:48–08:06]
- 実際の配置ではカメラを固定（dock）してシーン内での足場の見え方を確認しながら位置決め [08:12–08:18]
→ 「同じ資材アセットの見た目バリエーションを量産する」量産パターンとして、本プロジェクトの `project_scrapblitz_derived_attack_pattern.md` 的な発想（派生パターンの量産）と近い設計思想

### 5. 行き詰まったら別エリアに切り替える（進行管理のコツ）[11:04–11:11, 13:15–13:19]
- 「あるエリアで手が止まったと感じたら、他のエリアに切り替えてディテールや歴史性を足す」という進行の切り替えルール [11:04–11:11]
- セメントミキシングエリアの方向性に迷った際も、いったん別の作業（レンガの欠片配置）に切り替えている [13:15–13:27]
- 前景作業も「新鮮な目で見るために」いったん離れてから戻る、という運用 [11:28–11:32]

### 6. ブレンドマテリアルは Vertex Paint ではなく Mesh Paint Texture でレイヤーを塗る [16:53–17:48]
- 地面のブレンドマテリアルは、レイヤーごとの tiling 制御・texture パラメータ・material attributes を持ち、**Material Layer Blends** で合成 [16:53–17:10]
- レイヤーブレンドを駆動しているのは「paint」という名前の reroute ノード。**Vertex Painting の代わりに Mesh Paint Texture を使う** [17:13–17:25]
- 手順: 地面メッシュを選択 → Details パネルの Mesh Painting セクションで Advanced Settings を Override → Mesh Paint Mode → Texture Color タブ → Add ボタンで virtual texture を追加 → レイヤーをペイント [17:25–17:41]
- ライティング調整後、レイヤー同士の明暗差が強すぎたため、好みのレイヤーに近づける調整を実施（マテリアルは一発で決め切らず、ライティングとセットで反復調整するのが前提）[18:47–19:04]
- 山（piles）と地面の継ぎ目を隠すため、**山の色に近いレイヤーを一つ用意して交差部分のシームを隠す** [19:23–19:31]

### 7. Decal による汚し・シーム隠しは「コレクション外から補完」してでも使う [19:39–20:35]
- コレクションに含まれない decal を 3 種ダウンロードし、**風化表現とシーム隠し**に使用。これは「シームへの磨き上げ」として非常に強力な手法と明言 [19:39–19:52]
- decal 配置時は **Surface Snapping** を多用し、正しい向きを得る手間を削減 [19:52–20:00]
- 露出したコンクリートに漏水シミ（leakage stains）を追加後、前景アセットに**基本的な埃の堆積（dust accumulation）**を追加 [20:06–20:15]
- コレクション外の岩も追加し、ブレンドマテリアルに深みを持たせる補完材として使用 [20:22–20:35]
→ 産業系の汚し手法として「漏水シミ」「埃堆積」「岩でブレンド強化」の 3 点は本プロジェクトの廃工場ヤードの地面/壁の汚しに直結する参考

### 8. Light Function で雲の影を使い、静的ライティングに動きを足す [21:02–21:27]
- ダイナミズムを足す好みの方法として、**Directional Light に Light Function で雲の影を投影**する手法を挙げている [21:02–21:10]
- Light Function マテリアルは tiling・開始位置・雲の強度・コントラストを制御できる [21:10–21:17]
- 適用はシンプルに Directional Light の Light Function Material スロットへ割り当てるのみ [21:19–21:23]

### 9. 最終構図調整はフォーカルポイントのバランスで判断 [21:33–22:21]
- 空が多く何もない画面になっていたため、**カメラ角度を下げる**判断 [21:33–21:41]
- 前景の物を動かして**ビネットのように機能する自然な影**を作る [21:43–21:46]
- 足場を使って**長い影を作り、均一な光を崩す** [21:46–21:53]
- フォーカルポイントが画面右に偏っていると感じたら、**中央左にもう一つのフォーカルポイントを追加**し、視線が両方の間を往復できるようにする [22:11–22:23]
