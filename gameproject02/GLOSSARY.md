詳細は仕様書 `plans/buzzing-juggling-sedgewick.md` / 各キャラ `plans/chars/*.md` / `discussions/*.md` 参照。

初版：2026-05-24 / 粒度：コア語厳選

## 1. 操作・システム略語

| 略 | 正式名 | 一行説明 |
|---|---|---|
| **RC** | リパルスカウンター | 敵の特定大技に「相反する atklv 攻撃」を合わせて返すシステム。確定クリ + 100% gc + 専用予兆/SE |
| **OC** | OVERCLOCK | 一時強化システム。ウェーブクリア等でジェム出現 → 2 択選択で発動 |
| **OC-EX** | OVERCLOCK EX | OC の上位/派生枠（命名規約のみ確定・実装は順次） |
| **ULT** | アルティメット | SP 2 消費・地上限定・全画面 AoE（赤ドーム）。`c01_sp_ult01` |
| **MEGA** | メガクラッシュ | SP 1 消費・コンボ繋ぎ用 AoE。`c01_sp_mega01` |
| **SP** | スペシャル | SP ゲージ/ストック。MEGA/ULT/SP コマンド技の燃料 |
| **CR** | クレジット | ゲーム内通貨。本作は CR 一本化（新通貨追加は原則禁止） |
| **SA** | スーパーアーマー | 被弾でよろめかない耐性。雑魚 SA=2 / ボスは完全 SA + 解除トリガーあり |
| **BURST** | バースト（きりもみ離脱） | コンボ上限に達した敵を無敵回転で離脱させる強制ダウン。追撃不能 |
| **gc** | ゴアクリティカル | 必殺技固有の特別演出群。`gc_01〜06`（壁吹き飛ばし / 後方分裂 / 上半身打ち上げ / 叩きつけ放射 ほか） |
| **GRAB** | つかみ | くにおくん式・密着自動発動。投げで離脱 |
| **CJ** | キャンセルジャンプ | ヒット中 SPACE で大噴射ジャンプ（追撃継続用） |

## 2. 攻撃の強度指標（混同注意）

| 用語 | 範囲 | 説明 |
|---|---|---|
| **atklv** | lv01〜lv07 | 個々の攻撃ヒットの強さ。プレイヤー被弾ステートの振り分けキー |
| **atklv_air** | 1〜6 | 空中敵にヒットした時の atklv 上書き値（未定義なら atklv） |
| **atklv_down** | 5 or 7 | ダウン中の敵にヒットした時の atklv（undefined なら空振り） |
| **tier** | tier01〜tier06 | **敵側の強度ランク**。atklv とは別軸・**混同禁止** |

> よくある誤読：「tier06 = lv06」ではない。`tier` は敵の格、`atklv` は攻撃のヒット強度。

## 4. ステージ・フェーズ

| 用語 | 説明 |
|---|---|
| **Act** | ステージのテーマ括り。Act 1 = factory（廃工場）確定 |
| **Stage 1/2/3** | Act 内の 3 ステージ（例：stage01 外周ヤード → stage02 内部 → stage03 中央プラント） |
| **Wave** | ステージ内の敵出現単位。`wave-runner.js` で共通管理 |
| **Phase 1/2/3** | ① 開発フェーズ（Phase 2.4 完了 等）／② ボス戦の段階（HP 帯ごとの行動セット）。文脈で判別 |
| **HP ゲート** | ボス HP がフェーズ境界で 1 残しになり、メガクラ流用演出を挟んでから次フェーズへ進む仕組み |

## 5. アイテム・ドロップ

| 用語 | 説明 |
|---|---|
| **pickup** | 敵/コンテナから出る取得物の総称。HP 3 種 / SP / チップ 5 レアリティ |
| **HP burger** | HP 回復 pickup（小/中/大の 3 種） |
| **コンテナ** | ステージ配置の破壊可能箱。CR + pickup を吐く（`crate` / `gas-canister` / `oc-container`） |
| **hazard** | ステージギミック（落とし穴 / 地雷など。敵にも当たる） |
| **茶柱** | チップ pickup のレア演出（縦に立つ） |

## 6. 命名規則（早見）

| パターン | 例 | 意味 |
|---|---|---|
| `c{ID}_atk_{弱/強}_{連番}` | `c01_atk_l_01` | キャラ通常攻撃。弱 `s` / 強 `l` |
| `c{ID}_add_{連番}` | `c01_add_01` | 派生攻撃（J + 方向） |
| `c{ID}_sp_{種別}{連番}` | `c01_sp_mega01` / `c01_sp_02_short` | SP 消費技（mega / ult / 連番） |
| `boss{ID}_atk_{連番}` | `boss1_atk_05` | ボス攻撃カタログ |
| `enem{ID}` | `enem01` | 雑魚 ID |
| `gc_{連番}` | `gc_06` | ゴアクリティカル演出 ID |
