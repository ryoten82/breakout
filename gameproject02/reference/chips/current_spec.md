## 方式

**バックパックヒーロー方式のグリッドハメビルド構築。**

## 基本仕様

| 項目 | 内容 |
|------|------|
| グリッド | キャラ専用・**初期 4×4=16マス** → CR拡張で最大 6×6=36マス |
| チップの形 | 1×1〜3×3、L字・T字など多様 |
| 同時装備 | グリッドに収まる範囲で複数可 |
| 入れ替え | ターミナルでのみ（道中不可・テンポ重視） |
| ドロップ源 | **中ボス以上のみ**（雑魚・破壊オブジェクトからは出ない） |
| 自動配置 | おすすめ装備ボタン常設・初心者救済 |
| ヘルプ | チップ画面でいつでも閲覧可 |

## 装備プリセット

**チップ装備の保存スロット（プリセット）機能。ハクスラ定番。**

- 複数の装備セットを保存・切替できる（例：プリセット 3〜5 枠）
- 戦闘前にワンタッチで切替（攻撃特化 / 守備特化 / トレジャー特化 / 傭兵連れ等）
- **マーセナリーチップ採用時は特に効く**：「ソロ用ビルド」「傭兵連れビルド」を別プリセットに登録して即切替できると体験が大幅に良くなる

**実装時期：**
- 本作で必要になるかは未確定。マーセナリーチップが実装されるなら同時に欲しい
- それ以外でも、ステージ別の最適ビルドが分化してきたら必要性が出る
- Three.js プロト段階では優先度低。Unreal 移行後の UI 整備と合わせて検討

確定度：🟡（方針・実装時期は要検討）

## 装備画面 UI と BENCHMARK

**チップ配置と強化結果を同一画面で確認できる UI を必須とする。**

**要件：**
- チップグリッド（配置エディタ）と**強化後ステータス一覧**を**同一画面に同時表示**
- ステータス変化は配置を変えた瞬間にリアルタイム反映（試行錯誤を阻害しない）
- 隣接ボーナスの発生状態も可視化（光らせる・線で繋ぐ等）

**BENCHMARK（ベンチマーク・強化度の総合指標）：**
- 🟢 **名称決定：BENCHMARK / ベンチマーク**（2026-05-14）— PC 用語・自動車用語として馴染みがあり、「性能の総合指標」のニュアンスがそのまま機能する
- The Division シリーズのギアスコアを参考。装備全体の強さを**一つの数値**で要約
- 細かいステータスを読み解かなくても**強さの目安が即わかる**
- ビルド比較・周回ペース把握・マルチプレイ時の同行者の参考にも使える
- 数式は装備チップのレアリティ・効果量・隣接ボーナスを統合する形（具体式は実装時に確定）

**BENCHMARK による攻略指針（ステージ推奨）：**
- 各ステージに**推奨 BENCHMARK** を設定し、装備画面・ステージ選択画面で「このステージ推奨：◯◯」と表示
- 現在 BENCHMARK と比較してざっくりした攻略指針が取れる
- 「足りないからチップ整えるか」「余裕あるから挑戦するか」の判断を数字で支援
- 厳密な縛りではなく目安（推奨未満でも挑戦可）

**設計意図：**
- バックパックヒーロー方式は配置パズル性が肝。配置を変えた結果が即座に数字で見えることが意思決定の速度・楽しさを左右する
- ギアスコアは「自分のビルドが今どれくらい強いか」を毎回ステータス画面を眺めなくても把握できるシンプルな目安
- 北極星 1「ノイズ最小化」と整合

**実装メモ：**
- UI 実装時、ステータス一覧とグリッドの**同居レイアウト**を確保（タブ切替で別画面にしない）
- ギアスコアはセーブデータに保持し、出撃選択画面・装備プレビューでも表示

確定度：🔒（方針）／ 🟡（具体レイアウト・数式）

## チップ分類（装着対象）

すべてのチップは以下 2 系統のいずれかに属する：

| 分類 | 装着可能 | 主な用途 |
|------|---------|---------|
| **A. 汎用チップ** | 全キャラ装着可能 | 攻撃力・HP・SP・機動などキャラ共通のステータス強化、共通システム拡張 |
| **B. 専用チップ** | 各機体専用（指定キャラのみ） | 必殺技強化（プラズマカノン化等）・キャラ固有挙動の換装・専用シナジー |

- 必殺技強化チップ（PLASMA INDUCER / ANTI-AIR ROCKET / BURST CORE 等）は基本「B. 専用」枠
- 「汎用に見えてキャラごとに係数違い」は将来検討（混乱回避のため初期は明確に二分）
- クロスビルド構想（VIPER 用チップを別機体に装備可）は将来拡張枠。初期実装では専用＝指定キャラ限定

確定度：🔒（方針）

## レアリティと形

| レアリティ | 形 | 効果のスケール |
|-----------|-----|---------------|
| Common | 1×1 | 単一の小効果（攻撃+3% / HP+5 など） |
| Uncommon | 1×2 | 中効果＋簡易条件 |
| Rare | 2×2 / L字 | 強効果（HP70%以上で攻撃+10% など） |
| Epic | 2×3 / T字 | 複合効果＋隣接強化 |
| Legendary | 3×3 / 特殊形 | 大効果＋固有特殊効果（パリィ追加等） |

- **Legendary は「守り・サポート系」中心**（OVERCLOCK ＝攻めの軸と役割分離）
- 「強いけど大きいから入らない」嬉しい悩みを意図的に作る

## 効果カテゴリ

| 系統 | 効果例 |
|------|--------|
| 攻撃 | 攻撃力+x%・コンボダメージ+x%・特定属性+x% |
| 守備 | HP+x・被ダメ-x%・ノックバック減少 |
| 機動 | ダッシュCD-x%・ジャンプ高度+x |
| ゲージ | SP獲得+x%・初期SP+x% |
| **必殺技強化** | 特定コマンド技をベース版から強化版に置換（プラズマカノン化等・仕様書 §9.7） |
| 特殊（Legendary） | パリィ追加・ダッシュ回数+1・自然回復付与・攻撃中スーパーアーマー |

## 必殺技強化チップ（例）

パーツシステム廃止（仕様書 §28）に伴い、技強化を**装備換装可能なチップ**として再構築。
装備中のみ有効・外せばベース版に戻る。

| チップ名（仮） | 対応コマンド | 効果 | レアリティ目安 | 形目安 |
|--------------|-----------|------|--------------|--------|
| PLASMA INDUCER | ↓↘→+J | 弱いビーム → プラズマカノン（長距離・貫通・爆発） | Epic | 2×3 |
| ANTI-AIR ROCKET | ↓↑+J | 小ジャンプ噴射 → 対空キャノン（真上射撃・大きく上昇） | Epic | 2×3 |
| BURST CORE | J長押し | チャージパンチ → オーバーロードバースト（全方向爆発・画面揺れ） | Legendary | 3×3 |

**設計意図：**
- 旧パーツシステムの「Legendary 装備で技強化」をチップシステムに統合し、システムの一貫性を保つ
- グリッドに「強化チップを入れるか／別の攻撃系チップで埋めるか」のトレードオフ
- キャラ固有の必殺技強化チップを将来追加可能（VIPER 専用プラズマ・CANNON 専用バースト等）
- クロスビルド：他キャラ向けチップを装備して技を別物に変える将来拡張も視野

## 隣接ボーナス（パズル性の核心）

同じ手札でも配置で結果が変わる：

- 攻撃チップ同士隣接 → 攻撃チップ全体 +10%
- 守備チップが攻撃チップを囲む → 防御の 20% を攻撃へ転化
- 同系統 3 個以上クラスター → セットボーナス
- Legendary の周囲 4 マスは「強化フィールド」として隣接強化

## チップ合成（Stage3 クリアで解放・天井破り）

```
Common 3個   → Uncommon 1個
Uncommon 3個 → Rare 1個
Rare 3個     → Epic 1個
Epic 3個     → Legendary 1個
```

- 合成効果はランダム抽選（再ロール機能は後付け検討）
- 余ったチップが意味あるリソースに変わる
- Stage3 クリア前はアクセス不可（達成感演出）

## フレーバーテキスト

一部のチップには**フレーバーテキスト**が付く。

- 基本は **Legendary に数点**だけ付ける想定（数を絞って印象を残す）
- Common〜Epic は原則なし。**例外的に意味のあるチップ**（再入手不可・チュートリアル系等）には付ける
- 効果欄とは別枠の世界観テキスト・口調は自由（ゲーム的なメタ寄りも可）

**例：**
- ガーディアンモジュール（Uncommon・再入手不可）
  > このチップは再取得できないから大切にね

→ 全チップに付けるとコスト過大かつ印象が薄れる。少数の宝物に厳選することで Legendary を引いた時の特別感を担保する。

確定度：🔒（方針）／ 🟡（個別文面）

| 撃破対象 | 個数 | レアリティ内訳 |

| 中ボス | 1〜2 個 | Common 1〜2 ＋ Uncommon 0〜1 |

| ステージ2ボス | 3〜5 個 | Rare〜Epic 中心 |
